A Taste of What's Inside

Type Safety from Database to UI

This is what staff-level TypeScript looks like — zero any, zero runtime surprises.

ai-chat-route.ts 
import { Hono } from "hono";
import Anthropic from "@anthropic-ai/sdk";
import { z } from "zod";
import { zValidator } from "@hono/zod-validator";

// Single source of truth — validated at runtime, typed at compile time
const ChatRequestSchema = z.object({
  messages: z.array(z.object({
    role: z.enum(["user", "assistant"]),
    content: z.string().min(1).max(8192),
  })).min(1),
  model: z.enum(["claude-opus-4-5", "claude-sonnet-4-5"]).default("claude-sonnet-4-5"),
});

type ChatRequest = z.infer<typeof ChatRequestSchema>;

const client = new Anthropic();
const app = new Hono();

// Fully typed streaming endpoint — no Response gymnastics
app.post("/chat", zValidator("json", ChatRequestSchema), async (c) => {
  const { messages, model }: ChatRequest = c.req.valid("json");

  const stream = await client.messages.stream({
    model,
    max_tokens: 2048,
    messages,
  });

  return new Response(stream.toReadableStream(), {
    headers: { "Content-Type": "text/event-stream" },
  });
});

Getting the Most from This Course

How to Use This Curriculum

A field guide to working through 200+ hours of material without burning out or skipping ahead too early.

1
Read Sequentially Through Part I
Chapters 1–7 build on each other. Even experienced Python engineers will encounter TypeScript-specific concepts that require sequential exposure. Do not skip.
2
Type-Check Everything You Write
Run tsc --noEmit in watch mode on all exercises. Errors are the curriculum. Read them fully — TypeScript's error messages are dense but precise.
3
Navigate Parts II–V by Need
After completing foundations, Parts II–V can be read in any order based on what you're building. Backend engineer? Go to Part III. Frontend focused? Jump to Part IV.
4
End with the Case Studies
Part VI case studies assume all prior knowledge. They are architecture post-mortems — meant to synthesize everything you've learned by examining real production systems.
5
Build the Projects, Not Just Read Them
Each chapter's project section has a starter repo. Fork it, implement it yourself, then compare against the reference implementation. Reading TypeScript is not the same as writing it.
6
Reference the Authors' Own Work
Each chapter links to the author's primary resources — books, repositories, talks, and documentation. This curriculum is a curated entry point, not a ceiling.
Prerequisites

Who Is This For?

This curriculum has a specific audience. Know if you're in it before you start.

You Will Thrive If You Have

  • 2+ years of Python experience, including type hints with mypy or pyright
  • Comfort with functions, classes, modules, and basic OOP concepts
  • Experience with at least one REST API or web application, in any language
  • A terminal you're not afraid of — git, npm, file navigation
  • Patience for compiler errors (the type system will push back on you)

Helpful But Not Required

  • Prior JavaScript exposure (we assume none, but it helps)
  • React or any frontend framework experience
  • Database knowledge — SQL or NoSQL
  • Cloud or DevOps background
  • Prior exposure to compiled languages like Go, Rust, or Java
