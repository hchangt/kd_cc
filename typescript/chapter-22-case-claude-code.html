1 CLI Tools in TypeScript — The Landscape

Command-line interfaces are one of the best TypeScript first projects: the type system prevents entire categories of argument-parsing bugs, the ecosystem is mature, and shipping a binary via npm is dead simple. But before writing a line of code, pick your tools deliberately.

The Experience Layer

  • @clack/prompts — Beautiful interactive prompts (spinner, text, confirm). Replaces inquirer for most use-cases.
  • chalk — Terminal colors. Always check chalk.level so CI output stays clean.
  • ora — Elegant spinners for async work (thinking, tool execution).
  • boxen — Draw boxes around content (used for tool output headers).
  • cli-highlight — Syntax-highlight code blocks printed to the terminal.
  • chokidar — File watching (used in --watch mode).

2 Architecture Overview: How Claude Code Works

Claude Code is built around a tight loop: read user intent, ask Claude, execute whatever tools Claude requests, feed results back, repeat. This is the agentic loop. Understanding it is the key to building any AI CLI.

The Five Subsystems

  • REPL — Reads user input, manages the conversation history array, orchestrates the other subsystems.
  • AI Client — Wraps the Anthropic SDK. Handles streaming, retry on rate-limit, and maps Anthropic event types to internal StreamEvent types.
  • Tool System — A registry of typed tools (bash, read, write, search). Each tool has a Zod schema for its input — used both to generate the JSON Schema sent to Claude and to validate Claude’s tool-use inputs at runtime.
  • Context Manager — Tracks conversation history, CLAUDE.md file contents, and enforces token budgets by summarizing or truncating older messages.
  • Permission System — Before any tool executes, checks an allow/deny list. Dangerous operations (bash with rm -rf, file writes outside the project) require explicit approval.

Signal Flow

  1. User types a message. It’s appended to messages as { role: "user", content }.
  2. The AI client sends messages + system prompt + tool definitions to the Anthropic API.
  3. Claude streams back text tokens and/or tool_use blocks.
  4. If stop_reason === "tool_use": run each requested tool, collect tool_result blocks, push both the assistant message and the user tool-result message onto messages, then go to step 2.
  5. If stop_reason === "end_turn": render the final text to the terminal. Loop back to step 1.

4 The Tool System

The tool system is the heart of the agentic CLI. Claude decides which tools to call; we define what they do. The key insight: treat Claude’s tool inputs as untrusted user input. Always validate with Zod before execution.

Tool Interface — src/tools/index.ts

src/tools/index.ts
import { z } from 'zod'
import type Anthropic from '@anthropic-ai/sdk'

// ── Core types ──────────────────────────────────────────────────────────────

export type ToolResult =
  | { success: true;  output: string }
  | { success: false; error: string }

export interface Tool<TInput = unknown> {
  name:        string
  description: string
  inputSchema: z.ZodType<TInput>
  execute:     (input: TInput) => Promise<ToolResult>
}

// eslint-disable-next-line @typescript-eslint/no-explicit-any
export type AnyTool = Tool<any>

// ── Tool registry ───────────────────────────────────────────────────────────

export class ToolRegistry {
  private tools = new Map<string, AnyTool>()

  register<T>(tool: Tool<T>): this {
    this.tools.set(tool.name, tool as AnyTool)
    return this
  }

  get(name: string): AnyTool | undefined {
    return this.tools.get(name)
  }

  all(): AnyTool[] {
    return [...this.tools.values()]
  }

  /** Convert our tools to the format the Anthropic API expects */
  toAnthropicTools(): Anthropic.Tool[] {
    return this.all().map(tool => ({
      name:         tool.name,
      description:  tool.description,
      input_schema: zodToJsonSchema(tool.inputSchema),
    }))
  }
}

/** Minimal Zod-to-JSON-Schema converter for object schemas */
function zodToJsonSchema(schema: z.ZodType): Anthropic.Tool['input_schema'] {
  if (schema instanceof z.ZodObject) {
    const shape = schema.shape as Record<string, z.ZodType>
    const properties: Record<string, unknown> = {}
    const required: string[] = []

    for (const [key, value] of Object.entries(shape)) {
      properties[key] = zodTypeToJsonSchema(value)
      if (!(value instanceof z.ZodOptional)) required.push(key)
    }

    return { type: 'object', properties, required }
  }
  return { type: 'object', properties: {} }
}

function zodTypeToJsonSchema(type: z.ZodType): unknown {
  if (type instanceof z.ZodString)  return { type: 'string',  description: type.description }
  if (type instanceof z.ZodNumber)  return { type: 'number',  description: type.description }
  if (type instanceof z.ZodBoolean) return { type: 'boolean', description: type.description }
  if (type instanceof z.ZodOptional) return zodTypeToJsonSchema(type.unwrap())
  if (type instanceof z.ZodEnum)    return { type: 'string', enum: type.options }
  if (type instanceof z.ZodArray)   return { type: 'array',  items: zodTypeToJsonSchema(type.element) }
  return { type: 'string' }
}

/** Execute a tool call from Claude, with Zod validation */
export async function executeTool(
  registry: ToolRegistry,
  name: string,
  rawInput: unknown,
): Promise<ToolResult> {
  const tool = registry.get(name)
  if (!tool) {
    return { success: false, error: `Unknown tool: ${name}` }
  }

  const parsed = tool.inputSchema.safeParse(rawInput)
  if (!parsed.success) {
    return {
      success: false,
      error: `Invalid tool input for "${name}": ${parsed.error.message}`,
    }
  }

  try {
    return await tool.execute(parsed.data)
  } catch (err) {
    return { success: false, error: String(err) }
  }
}

Bash Tool — src/tools/bash.ts

src/tools/bash.ts
import { z } from 'zod'
import { exec } from 'node:child_process'
import { promisify } from 'node:util'
import type { Tool } from './index.js'

const execAsync = promisify(exec)

const BashInput = z.object({
  command: z.string().describe('The shell command to execute'),
  timeout: z.number().optional().describe('Timeout in milliseconds (default 30000)'),
})

type BashInput = z.infer<typeof BashInput>

export const bashTool: Tool<BashInput> = {
  name:        'bash',
  description: 'Execute a shell command in the project directory. Use for running tests, git commands, npm scripts, or any CLI tool.',
  inputSchema: BashInput,

  async execute({ command, timeout = 30_000 }) {
    try {
      const { stdout, stderr } = await execAsync(command, {
        timeout,
        maxBuffer: 10 * 1024 * 1024, // 10 MB
      })

      const output = [stdout, stderr].filter(Boolean).join('\n').trim()
      return {
        success: true,
        output: output || '(command produced no output)',
      }
    } catch (err: unknown) {
      const error = err as { stdout?: string; stderr?: string; message?: string }
      const detail = [error.stdout, error.stderr, error.message]
        .filter(Boolean)
        .join('\n')
        .trim()
      return { success: false, error: detail || String(err) }
    }
  },
}

Read Tool — src/tools/read.ts

src/tools/read.ts
import { z } from 'zod'
import { readFile } from 'node:fs/promises'
import { resolve } from 'node:path'
import type { Tool } from './index.js'

const ReadInput = z.object({
  path:   z.string().describe('Absolute or relative path to the file to read'),
  offset: z.number().optional().describe('Line number to start reading from (1-indexed)'),
  limit:  z.number().optional().describe('Maximum number of lines to read'),
})

type ReadInput = z.infer<typeof ReadInput>

export const readTool: Tool<ReadInput> = {
  name:        'read',
  description: 'Read the contents of a file. Optionally specify offset and limit to read a slice.',
  inputSchema: ReadInput,

  async execute({ path, offset, limit }) {
    try {
      const absPath = resolve(path)
      const raw = await readFile(absPath, 'utf8')
      const lines = raw.split('\n')

      const start = offset !== undefined ? Math.max(0, offset - 1) : 0
      const end   = limit  !== undefined ? start + limit : lines.length
      const slice = lines.slice(start, end)

      // Prefix with line numbers (like cat -n)
      const numbered = slice.map((line, i) => {
        const lineNum = String(start + i + 1).padStart(4, ' ')
        return `${lineNum}\t${line}`
      })

      return {
        success: true,
        output: numbered.join('\n'),
      }
    } catch (err: unknown) {
      return { success: false, error: String(err) }
    }
  },
}

Search Tool — src/tools/search.ts

src/tools/search.ts
import { z } from 'zod'
import { exec } from 'node:child_process'
import { promisify } from 'node:util'
import type { Tool } from './index.js'

const execAsync = promisify(exec)

const SearchInput = z.object({
  pattern:    z.string().describe('Regex pattern to search for'),
  path:       z.string().optional().describe('Directory or file to search in (default: current dir)'),
  filePattern: z.string().optional().describe('Glob pattern to filter files (e.g. "*.ts")'),
  ignoreCase: z.boolean().optional().describe('Case-insensitive search'),
})

type SearchInput = z.infer<typeof SearchInput>

export const searchTool: Tool<SearchInput> = {
  name:        'search',
  description: 'Search for a pattern in the codebase using ripgrep. Returns matching lines with file paths and line numbers.',
  inputSchema: SearchInput,

  async execute({ pattern, path = '.', filePattern, ignoreCase }) {
    // Build ripgrep command; fall back to grep if rg not available
    const flags = [
      '--line-number',
      '--with-filename',
      '--color=never',
      '--max-count=50',      // cap results
      ignoreCase ? '--ignore-case' : '',
      filePattern ? `--glob '${filePattern}'` : '',
    ].filter(Boolean).join(' ')

    const rgCmd  = `rg ${flags} '${pattern.replace(/'/g, "\\'")}' ${path} 2>/dev/null`
    const grepCmd = `grep -r -n ${ignoreCase ? '-i' : ''} '${pattern.replace(/'/g, "\\'")}' ${path} ${filePattern ? `--include='${filePattern}'` : ''} 2>/dev/null | head -50`

    // Try ripgrep first, fall back to grep
    for (const cmd of [rgCmd, grepCmd]) {
      try {
        const { stdout } = await execAsync(cmd, { maxBuffer: 5 * 1024 * 1024 })
        if (stdout.trim()) {
          return { success: true, output: stdout.trim() }
        }
      } catch {
        // continue to next command
      }
    }

    return { success: true, output: 'No matches found.' }
  },
}

5 The Anthropic Client Wrapper

Stream Event Types — src/ai/streaming.ts

src/ai/streaming.ts
// Discriminated union of all events we care about from the stream
export type StreamEvent =
  | { type: 'text_delta';        text: string }
  | { type: 'tool_use_start';    id: string; name: string }
  | { type: 'tool_use_delta';    id: string; partialJson: string }
  | { type: 'tool_use_complete'; id: string; name: string; input: unknown }
  | { type: 'message_stop';      stopReason: string }
  | { type: 'error';             message: string }

// Accumulates partial JSON for a tool_use block during streaming
export class ToolInputAccumulator {
  private buffers = new Map<string, string>()

  append(id: string, chunk: string): void {
    this.buffers.set(id, (this.buffers.get(id) ?? '') + chunk)
  }

  finalize(id: string): unknown {
    const buf = this.buffers.get(id) ?? '{}'
    this.buffers.delete(id)
    try {
      return JSON.parse(buf)
    } catch {
      return {}
    }
  }
}

AI Client — src/ai/client.ts

src/ai/client.ts
import Anthropic from '@anthropic-ai/sdk'
import type { Config } from '../config/settings.js'
import type { ToolRegistry } from '../tools/index.js'
import { ToolInputAccumulator, type StreamEvent } from './streaming.js'

export const SYSTEM_PROMPT = `You are tsai, an expert TypeScript AI assistant operating in a developer's terminal.
You have access to tools that let you read files, write files, run shell commands, and search the codebase.
Be concise but complete. When you make a change to a file, always show a summary of what changed.
Prefer targeted edits over full rewrites. Always run the TypeScript type-checker after edits.`

export class AIClient {
  private client: Anthropic

  constructor(
    private config: Config,
    private registry: ToolRegistry,
  ) {
    this.client = new Anthropic({ apiKey: config.apiKey })
  }

  /** Stream a conversation turn, yielding structured events */
  async *stream(
    messages: Anthropic.MessageParam[],
  ): AsyncGenerator<StreamEvent> {
    const accumulator = new ToolInputAccumulator()
    // Track active tool uses: id -> name
    const activeTools = new Map<string, string>()

    let stream: Awaited<ReturnType<typeof this.client.messages.stream>>

    try {
      stream = this.client.messages.stream({
        model:      this.config.model,
        max_tokens: this.config.maxTokens,
        system:     SYSTEM_PROMPT,
        messages,
        tools:      this.registry.toAnthropicTools(),
      })
    } catch (err) {
      yield { type: 'error', message: String(err) }
      return
    }

    for await (const event of stream) {
      switch (event.type) {
        case 'content_block_start':
          if (event.content_block.type === 'tool_use') {
            const { id, name } = event.content_block
            activeTools.set(id, name)
            yield { type: 'tool_use_start', id, name }
          }
          break

        case 'content_block_delta':
          if (event.delta.type === 'text_delta') {
            yield { type: 'text_delta', text: event.delta.text }
          }
          if (event.delta.type === 'input_json_delta') {
            // Find the current tool's id from the index
            const id = [...activeTools.keys()][event.index] ?? ''
            accumulator.append(id, event.delta.partial_json)
            yield { type: 'tool_use_delta', id, partialJson: event.delta.partial_json }
          }
          break

        case 'content_block_stop': {
          // Find the id for this content block index
          const toolEntries = [...activeTools.entries()]
          const entry = toolEntries[event.index]
          if (entry) {
            const [id, name] = entry
            const input = accumulator.finalize(id)
            activeTools.delete(id)
            yield { type: 'tool_use_complete', id, name, input }
          }
          break
        }

        case 'message_delta':
          if (event.delta.stop_reason) {
            yield { type: 'message_stop', stopReason: event.delta.stop_reason }
          }
          break
      }
    }
  }

  /** Non-streaming: create a message and return it (used in tests) */
  async createMessage(
    messages: Anthropic.MessageParam[],
  ): Promise<Anthropic.Message> {
    return this.client.messages.create({
      model:      this.config.model,
      max_tokens: this.config.maxTokens,
      system:     SYSTEM_PROMPT,
      messages,
      tools:      this.registry.toAnthropicTools(),
    })
  }
}

Context Manager — src/ai/context.ts

src/ai/context.ts
import { readFile } from 'node:fs/promises'
import { join } from 'node:path'
import type Anthropic from '@anthropic-ai/sdk'

export const MAX_MESSAGES = 100
export const SUMMARIZE_THRESHOLD = 80

export class ConversationContext {
  messages: Anthropic.MessageParam[] = []
  private claudeMd: string | null = null

  async loadClaudeMd(cwd: string = process.cwd()): Promise<void> {
    // Load CLAUDE.md from project root and user home, merging both
    const paths = [
      join(cwd, 'CLAUDE.md'),
      join(process.env['HOME'] ?? '~', '.claude', 'CLAUDE.md'),
    ]
    const contents: string[] = []
    for (const p of paths) {
      try {
        contents.push(await readFile(p, 'utf8'))
      } catch {
        // not found, skip
      }
    }
    this.claudeMd = contents.length > 0 ? contents.join('\n\n---\n\n') : null
  }

  getSystemAddendum(): string {
    if (!this.claudeMd) return ''
    return `\n\n<claude_md>\n${this.claudeMd}\n</claude_md>`
  }

  push(message: Anthropic.MessageParam): void {
    this.messages.push(message)
    // Hard cap: drop oldest pairs if we exceed the limit
    if (this.messages.length > MAX_MESSAGES) {
      this.messages = this.messages.slice(-MAX_MESSAGES)
    }
  }

  /** Estimate token count (rough: ~4 chars per token) */
  estimatedTokens(): number {
    const text = this.messages
      .flatMap(m => (typeof m.content === 'string' ? [m.content] : m.content.map(b => 'text' in b ? b.text : '')))
      .join('')
    return Math.ceil(text.length / 4)
  }
}

6 The REPL Loop

The REPL is the most complex piece. It must handle streaming text, interleaved tool-use blocks, recursive tool loops, and graceful shutdown all at once.

The Agentic Loop — src/cli/repl.ts

src/cli/repl.ts
import * as p from '@clack/prompts'
import chalk from 'chalk'
import type Anthropic from '@anthropic-ai/sdk'
import type { AIClient } from '../ai/client.js'
import type { ConversationContext } from '../ai/context.js'
import type { ToolRegistry } from '../tools/index.js'
import { executeTool } from '../tools/index.js'
import {
  displayText,
  displayToolStart,
  displayToolResult,
  displayError,
  displayThinking,
} from '../utils/display.js'
import type { Config } from '../config/settings.js'
import { checkPermission } from '../utils/permissions.js'

export async function startRepl(
  client:   AIClient,
  context:  ConversationContext,
  registry: ToolRegistry,
  config:   Config,
): Promise<void> {
  // Load CLAUDE.md context
  await context.loadClaudeMd()

  console.log(
    chalk.bold.hex('#4F46E5')('tsai') +
    chalk.gray(' — TypeScript AI Assistant') +
    '\n' +
    chalk.gray('Type your message, /exit to quit, /clear to reset context') +
    '\n'
  )

  // Main REPL loop
  while (true) {
    const input = await p.text({
      message: '',
      placeholder: 'Ask tsai anything about your TypeScript project...',
    })

    // Handle clack cancellation (Ctrl+C)
    if (p.isCancel(input)) {
      p.outro(chalk.gray('Goodbye!'))
      process.exit(0)
    }

    const text = (input as string).trim()
    if (!text) continue

    // Slash commands
    if (text === '/exit') {
      p.outro(chalk.gray('Goodbye!'))
      process.exit(0)
    }
    if (text === '/clear') {
      context.messages = []
      console.log(chalk.gray('Context cleared.\n'))
      continue
    }
    if (text === '/tokens') {
      console.log(chalk.gray(`Estimated tokens in context: ~${context.estimatedTokens()}\n`))
      continue
    }

    // Add user message and run the agentic loop
    context.push({ role: 'user', content: text })
    await runAgenticLoop(client, context, registry, config)
  }
}

/**
 * The agentic loop: send messages to Claude, handle tool use,
 * feed results back, repeat until stop_reason === 'end_turn'.
 */
async function runAgenticLoop(
  client:   AIClient,
  context:  ConversationContext,
  registry: ToolRegistry,
  config:   Config,
): Promise<void> {
  const stopThinking = displayThinking()

  // Collect the full assistant response (may include text and tool_use blocks)
  const assistantContent: Anthropic.ContentBlock[] = []
  let currentText = ''
  let firstChunk  = true

  // Pending tool calls: id -> { name, input }
  const pendingTools = new Map<string, { name: string; input: unknown }>()

  try {
    for await (const event of client.stream(context.messages)) {
      switch (event.type) {
        case 'text_delta':
          if (firstChunk) {
            stopThinking()
            firstChunk = false
            process.stdout.write('\n')
          }
          currentText += event.text
          displayText(event.text)  // stream character by character
          break

        case 'tool_use_start':
          if (firstChunk) {
            stopThinking()
            firstChunk = false
          }
          pendingTools.set(event.id, { name: event.name, input: null })
          break

        case 'tool_use_complete':
          pendingTools.set(event.id, { name: event.name, input: event.input })
          break

        case 'message_stop':
          // Flush accumulated text into content blocks
          if (currentText) {
            assistantContent.push({ type: 'text', text: currentText })
            currentText = ''
          }
          break

        case 'error':
          stopThinking()
          displayError(event.message)
          return
      }
    }
  } finally {
    stopThinking()
  }

  // If no tool use: we're done
  if (pendingTools.size === 0) {
    if (currentText) {
      assistantContent.push({ type: 'text', text: currentText })
    }
    if (assistantContent.length > 0) {
      context.push({ role: 'assistant', content: assistantContent })
    }
    process.stdout.write('\n\n')
    return
  }

  // Execute tool calls and collect results
  const toolResultContents: Anthropic.ToolResultBlockParam[] = []

  for (const [id, { name, input }] of pendingTools.entries()) {
    // Add tool_use block to assistant content
    assistantContent.push({
      type:  'tool_use',
      id,
      name,
      input: input ?? {},
    } as Anthropic.ToolUseBlock)

    // Check permissions before executing
    const allowed = await checkPermission(name, input, config)
    if (!allowed) {
      toolResultContents.push({
        type:        'tool_result',
        tool_use_id: id,
        content:     'Permission denied by user.',
        is_error:    true,
      })
      continue
    }

    displayToolStart(name, input)
    const result = await executeTool(registry, name, input)
    displayToolResult(result)

    toolResultContents.push({
      type:        'tool_result',
      tool_use_id: id,
      content:     result.success ? result.output : result.error,
      is_error:    !result.success,
    })
  }

  // Push assistant message (with tool_use blocks) and tool results
  context.push({ role: 'assistant', content: assistantContent })
  context.push({ role: 'user',      content: toolResultContents })

  // Recurse: Claude will process tool results and either respond or request more tools
  await runAgenticLoop(client, context, registry, config)
}

export function displayToolStart(name: string, input: unknown): void {
  const label = chalk.bold.hex('#0D9488')(`Tool: ${name}`)
  const detail = summarizeInput(name, input)
  process.stdout.write('\n' + chalk.gray('  ') + label + chalk.gray(` — ${detail}`) + '\n')
}

function summarizeInput(name: string, input: unknown): string {
  if (!input || typeof input !== 'object') return ''
  const obj = input as Record<string, unknown>
  switch (name) {
    case 'bash':   return chalk.italic(String(obj['command'] ?? '').slice(0, 80))
    case 'read':   return chalk.italic(String(obj['path'] ?? ''))
    case 'write':  return chalk.italic(String(obj['path'] ?? ''))
    case 'search': return chalk.italic(`"${obj['pattern'] ?? ''}"`)
    default:       return JSON.stringify(input).slice(0, 80)
  }
}

export function displayToolResult(result: { success: boolean; output?: string; error?: string }): void {
  if (result.success) {
    const lines = (result.output ?? '').split('\n').slice(0, 20) // cap preview
    const preview = lines.join('\n')
    if (preview.trim()) {
      const box = boxen(chalk.gray(preview), {
        padding:     { top: 0, bottom: 0, left: 1, right: 1 },
        borderColor: 'gray',
        borderStyle: 'round',
        dimBorder:   true,
      })
      console.log(box)
    }
  } else {
    console.log(chalk.red('  Error: ') + chalk.gray(result.error ?? 'unknown error'))
  }
}

import { z } from 'zod'
import { readFile } from 'node:fs/promises'
import { join } from 'node:path'

// ── Schema ───────────────────────────────────────────────────────────────────

export const PermissionModeSchema = z.enum(['auto', 'ask', 'deny-all'])
export type PermissionMode = z.infer<typeof PermissionModeSchema>

export const ConfigSchema = z.object({
  apiKey:       z.string().optional(),
  model:        z.enum(['claude-opus-4-7', 'claude-sonnet-4-6', 'claude-haiku-4-5'])
                  .default('claude-sonnet-4-6'),
  maxTokens:    z.number().int().positive().default(8096),
  allowedTools: z.array(z.string()).default(['bash', 'read', 'write', 'search']),
  permissions:  PermissionModeSchema.default('ask'),
  pathAllowlist: z.array(z.string()).default([]),  // extra paths write tool may access
})

export type Config = z.infer<typeof ConfigSchema>

// ── Loader ───────────────────────────────────────────────────────────────────

/** Load config from (in priority order):
 *  1. Environment variables
 *  2. Project config: .tsai/config.json
 *  3. Global config:  ~/.tsai/config.json
 *  4. Built-in defaults (from Zod schema)
 */
export async function loadConfig(): Promise<Config> {
  const home    = process.env['HOME'] ?? process.env['USERPROFILE'] ?? ''
  const globalPath  = join(home, '.tsai', 'config.json')
  const projectPath = join(process.cwd(), '.tsai', 'config.json')

  const layers: Record<string, unknown>[] = [{}]

  // Load global config
  try {
    const raw = await readFile(globalPath, 'utf8')
    layers.push(JSON.parse(raw) as Record<string, unknown>)
  } catch { /* no global config */ }

  // Load project config (overrides global)
  try {
    const raw = await readFile(projectPath, 'utf8')
    layers.push(JSON.parse(raw) as Record<string, unknown>)
  } catch { /* no project config */ }

  // Environment overrides (highest priority)
  const envOverrides: Record<string, unknown> = {}
  if (process.env['ANTHROPIC_API_KEY']) {
    envOverrides['apiKey'] = process.env['ANTHROPIC_API_KEY']
  }
  if (process.env['TSAI_MODEL']) {
    envOverrides['model'] = process.env['TSAI_MODEL']
  }
  layers.push(envOverrides)

  const merged = Object.assign({}, ...layers)
  const parsed = ConfigSchema.safeParse(merged)

  if (!parsed.success) {
    throw new Error(`Invalid config: ${parsed.error.message}`)
  }

  if (!parsed.data.apiKey) {
    throw new Error(
      'No API key found. Set ANTHROPIC_API_KEY or add "apiKey" to ~/.tsai/config.json'
    )
  }

  return parsed.data
}

Permission System — src/utils/permissions.ts

src/utils/permissions.ts
import * as p from '@clack/prompts'
import chalk from 'chalk'
import { resolve } from 'node:path'
import type { Config } from '../config/settings.js'

// Commands that require explicit confirmation regardless of mode
const DANGEROUS_PATTERNS = [
  /rm\s+-rf/,
  /sudo\s+/,
  />\s*\/dev\//,
  /dd\s+if=/,
  /mkfs/,
  /format\s+/,
]

/** Returns true if the tool should proceed, false to deny */
export async function checkPermission(
  toolName: string,
  input:    unknown,
  config:   Config,
): Promise<boolean> {
  // Respect allowedTools list
  if (!config.allowedTools.includes(toolName)) {
    console.log(chalk.red(`  Blocked: tool "${toolName}" not in allowedTools`))
    return false
  }

  // auto mode: allow everything in the allowedTools list
  if (config.permissions === 'auto') return true

  // deny-all mode: nothing runs
  if (config.permissions === 'deny-all') return false

  // ask mode: check for dangerous patterns, then prompt
  if (toolName === 'bash' && typeof input === 'object' && input !== null) {
    const cmd = (input as Record<string, unknown>)['command']
    if (typeof cmd === 'string') {
      for (const pattern of DANGEROUS_PATTERNS) {
        if (pattern.test(cmd)) {
          const confirmed = await p.confirm({
            message: chalk.red(`Dangerous command detected:\n  ${cmd}\n  Allow?`),
            initialValue: false,
          })
          return !p.isCancel(confirmed) && (confirmed as boolean)
        }
      }
    }
  }

  if (toolName === 'write' && typeof input === 'object' && input !== null) {
    const writePath = (input as Record<string, unknown>)['path']
    if (typeof writePath === 'string') {
      const abs = resolve(writePath)
      const cwd = process.cwd()
      // Allow writes inside project dir or explicitly allowed paths
      const allowed =
        abs.startsWith(cwd) ||
        config.pathAllowlist.some(p2 => abs.startsWith(resolve(p2)))

      if (!allowed) {
        const confirmed = await p.confirm({
          message: `Write to ${abs} (outside project)? Allow?`,
          initialValue: false,
        })
        return !p.isCancel(confirmed) && (confirmed as boolean)
      }
    }
  }

  return true
}

12 Lessons Learned

💡
Lesson Learned — Zod is not optional

Claude’s tool inputs are untrusted. The model may hallucinate field names or send the wrong types. Without Zod validation, you get runtime TypeErrors that are nearly impossible to debug. With Zod, you get a clean error message that goes back to Claude as a tool_result with is_error: true, and Claude self-corrects.

⏳
Lesson Learned — Streaming is the UX

Without streaming, users see nothing for 5–15 seconds, then a wall of text. With streaming, they see the first characters within 300ms. This is not a nice-to-have — it is the entire difference between a tool that feels alive and one that feels broken. Implement streaming from day one.

📈
Lesson Learned — Context window management is the hardest problem

Long sessions accumulate messages fast. Tool results can be enormous (reading a large file, running npm install). You need to: (1) cap tool output at a reasonable size, (2) track estimated token usage, (3) summarize or truncate old messages. The ConversationContext class in this chapter does the bare minimum. Production tools need a proper summarization strategy using a cheap model.

🛡
Lesson Learned — Discriminated unions prevent entire bug classes

The ToolResult and StreamEvent discriminated unions mean TypeScript forces you to handle every case. You cannot accidentally treat a tool_use_start event as a text_delta. This caught dozens of subtle event-ordering bugs during development that would have been silent runtime failures in JavaScript.

🔧
Lesson Learned — Async generators are the right abstraction

The async function* / for await...of pattern fits streaming AI responses perfectly. The caller gets a clean iterator; the implementation handles all the SSE complexity inside the generator. Compare to callback-based or EventEmitter-based streaming: the generator version is half the code and trivial to test.

🏗
Architecture Note — Key TypeScript Patterns
  • Discriminated unions — ToolResult, StreamEvent: exhaustive handling
  • Async generators — client.stream(): clean streaming abstraction
  • Zod for runtime validation — all AI outputs, all config files
  • Generic tool registry — Tool<TInput>: type-safe without losing flexibility
  • Stateless AI client — inject messages, get stream back; trivially testable
  • exactOptionalPropertyTypes — catches subtle undefined vs missing bugs in tool inputs
  • noUncheckedIndexedAccess — forced us to handle the case where toolEntries[event.index] might be undefined
✨
AI Era Note — This pattern scales

The architecture in this chapter is the same pattern used by Claude Code, Cursor, GitHub Copilot Workspace, and every serious AI coding tool. The specifics differ but the shape is identical: REPL loop → stateless AI client → typed tool registry → permission gate → agentic loop. Master this pattern and you can build any AI agent.
