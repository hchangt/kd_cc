1. Why Distributed Training

GPT-3 (175B params) needs ~350 GB in FP16 just for weights — an A100 has 80 GB. Training memory is 3-4× inference: you need activations, gradients, and optimizer states simultaneously. A single Adam step on a 70B model requires ~840 GB of GPU memory.

Memory math for a transformer:
Parameters: P × 2 bytes (FP16) | Gradients: P × 2 bytes | Adam states: P × 8 bytes (FP32 master weights + m + v)
Total ≈ 12 × P bytes → 7B model needs ~84 GB, 70B model needs ~840 GB

Three Axes of Parallelism

  • Data Parallelism (DP): Same model on every GPU, different data shards. Gradients averaged across GPUs.
  • Tensor Parallelism (TP): Individual layer weight matrices split across GPUs (intra-layer).
  • Pipeline Parallelism (PP): Different layers assigned to different GPUs (inter-layer).

2. Data Parallelism (DDP)

PyTorch DDP replicates the model on each GPU. Each GPU processes a different mini-batch, computes gradients, then an AllReduce operation averages gradients across all ranks before the optimizer step. Communication overlaps with backward pass via gradient bucketing.

sequenceDiagram participant GPU0 participant GPU1 participant GPU2 participant GPU3 Note over GPU0,GPU3: Forward pass (different batches) GPU0->>GPU0: loss0, grad0 GPU1->>GPU1: loss1, grad1 GPU2->>GPU2: loss2, grad2 GPU3->>GPU3: loss3, grad3 Note over GPU0,GPU3: AllReduce (Ring-AllReduce) GPU0->>GPU1: partial grad GPU1->>GPU2: partial grad GPU2->>GPU3: partial grad GPU3->>GPU0: partial grad Note over GPU0,GPU3: All GPUs have avg gradient → optimizer step

Complete DDP Training Script

"""
ddp_train.py — multi-GPU + multi-node DDP training
Launch: torchrun --nproc_per_node=8 --nnodes=2 --node_rank=0
        --master_addr=10.0.0.1 --master_port=29500 ddp_train.py
"""
import os, torch, torch.nn as nn
from torch.nn.parallel import DistributedDataParallel as DDP
from torch.utils.data import DataLoader, DistributedSampler
from torch.distributed import init_process_group, destroy_process_group

def setup():
    init_process_group(backend="nccl")   # NCCL for GPU-GPU comms
    torch.cuda.set_device(int(os.environ["LOCAL_RANK"]))

def cleanup():
    destroy_process_group()

def train(rank, world_size, epochs=3):
    setup()
    device = torch.device(f"cuda:{os.environ['LOCAL_RANK']}")

    # Model — wrap AFTER moving to device
    model = MyTransformer().to(device)
    model = DDP(model, device_ids=[device.index],
                find_unused_parameters=False)  # faster when all params used

    # Sampler ensures each rank sees non-overlapping data
    dataset = MyDataset()
    sampler = DistributedSampler(dataset, num_replicas=world_size,
                                 rank=rank, shuffle=True, drop_last=True)
    loader  = DataLoader(dataset, batch_size=64, sampler=sampler,
                         num_workers=4, pin_memory=True,
                         persistent_workers=True)

    optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)
    scaler    = torch.cuda.amp.GradScaler()          # for AMP

    # Gradient accumulation: effective_batch = batch_size * world_size * accum_steps
    ACCUM_STEPS = 4
    optimizer.zero_grad()

    for epoch in range(epochs):
        sampler.set_epoch(epoch)   # reshuffle across epochs
        for step, (x, y) in enumerate(loader):
            x, y = x.to(device, non_blocking=True), y.to(device, non_blocking=True)

            with torch.autocast(device_type="cuda", dtype=torch.bfloat16):
                loss = model(x, y) / ACCUM_STEPS

            scaler.scale(loss).backward()

            if (step + 1) % ACCUM_STEPS == 0:
                scaler.unscale_(optimizer)
                torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
                scaler.step(optimizer)
                scaler.update()
                optimizer.zero_grad()

        # Only rank 0 saves checkpoints
        if rank == 0 and (epoch + 1) % 1 == 0:
            torch.save({"model": model.module.state_dict(),
                        "opt":   optimizer.state_dict(),
                        "epoch": epoch},
                       f"ckpt_epoch{epoch}.pt")

    cleanup()

if __name__ == "__main__":
    import torch.multiprocessing as mp
    rank      = int(os.environ["RANK"])
    world     = int(os.environ["WORLD_SIZE"])
    train(rank, world)

3. Model & Tensor Parallelism

Tensor Parallelism (Megatron-style)

Column-parallel: split weight matrix along output dimension — each GPU computes a partial output. Row-parallel: split along input dimension — requires AllReduce to sum partial results. For MLP: column-parallel on W1, row-parallel on W2 → only one AllReduce per layer.

// MLP with 4-way Tensor Parallelism
GPU0: W1[0:H/4, :] | GPU1: W1[H/4:H/2, :] | GPU2: W1[H/2:3H/4, :] | GPU3: W1[3H/4:H, :]
→ each GPU computes partial GELU → all-gather → row-parallel W2 → allreduce

Pipeline Parallelism

  • GPipe: flush pipeline each batch. Simple but GPU idle time (bubble) = (p-1)/p where p = pipeline stages.
  • PipeDream: interleave forward/backward of different micro-batches. Reduces bubble but needs weight stashing.
  • 1F1B (One-Forward-One-Backward): steady state alternates F and B micro-batches. Bubble = (p-1)/(m+p-1) where m = micro-batches.

4. ZeRO Optimization (DeepSpeed)

ZeRO (Zero Redundancy Optimizer) eliminates redundant memory by partitioning optimizer states, gradients, and parameters across data-parallel ranks — while DDP keeps full copies everywhere.

ZeRO StageWhat's PartitionedMemory/GPU (7B, 64 GPUs)Communication Overhead
Baseline DDPNothing~84 GB1× AllReduce
ZeRO-1Optimizer states~31 GB1× AllReduce
ZeRO-2Optimizer states + gradients~18 GB1× AllReduce
ZeRO-3All (params + grads + opt)~1.5 GB3× AllGather/ReduceScatter
ZeRO-InfinityZeRO-3 + NVMe offload~0.5 GB GPUCPU/NVMe bandwidth bound

Training with DeepSpeed

"""
deepspeed_train.py
Launch: deepspeed --num_gpus=8 deepspeed_train.py --deepspeed ds_config.json
"""
import deepspeed, torch, os
from transformers import AutoModelForCausalLM, AutoTokenizer

def main():
    # deepspeed.init_distributed() called automatically
    model     = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-2-7b-hf")
    tokenizer = AutoTokenizer.from_pretrained("meta-llama/Llama-2-7b-hf")

    optimizer  = torch.optim.AdamW(model.parameters(), lr=1e-4)
    lr_sched   = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=1000)

    # DeepSpeed engine wraps model, optimizer, lr_scheduler
    model_engine, optimizer, _, lr_sched = deepspeed.initialize(
        model=model,
        optimizer=optimizer,
        lr_scheduler=lr_sched,
        config="ds_config.json"
    )

    dataset = build_dataset(tokenizer)
    loader  = build_loader(dataset, model_engine.local_rank)

    for epoch in range(3):
        for step, batch in enumerate(loader):
            batch = {k: v.to(model_engine.local_rank) for k, v in batch.items()}
            outputs = model_engine(**batch)
            loss    = outputs.loss
            model_engine.backward(loss)       # handles scaler + ZeRO internally
            model_engine.step()               # optimizer + lr_scheduler step

            if step % 100 == 0 and model_engine.local_rank == 0:
                print(f"epoch={epoch} step={step} loss={loss.item():.4f}")

        # DeepSpeed checkpoint (all ranks save their shard)
        model_engine.save_checkpoint(f"./ckpts/", tag=f"epoch{epoch}")

if __name__ == "__main__":
    main()

5. FSDP (Fully Sharded Data Parallel)

PyTorch native FSDP (torch 1.12+) implements ZeRO-3 semantics without DeepSpeed. Each parameter is sharded across ranks; AllGather is called before forward/backward on each module, then parameters are discarded after use.

FSDP Training Script with Wrapping Policy

import torch
from torch.distributed.fsdp import FullyShardedDataParallel as FSDP, MixedPrecision
from torch.distributed.fsdp.wrap import transformer_auto_wrap_policy
from torch.distributed.fsdp import BackwardPrefetch, ShardingStrategy
from torch.distributed.fsdp.fully_sharded_data_parallel import CPUOffload
from functools import partial
import os
from torch.distributed import init_process_group

def setup():
    init_process_group(backend="nccl")
    torch.cuda.set_device(int(os.environ["LOCAL_RANK"]))

def build_fsdp_model(model_cls, layer_cls):
    """Wrap transformer with FSDP — shard each transformer layer independently."""
    # Auto-wrap policy: wrap each TransformerDecoderLayer as an FSDP unit
    wrap_policy = partial(transformer_auto_wrap_policy, transformer_layer_cls={layer_cls})

    mp_policy = MixedPrecision(
        param_dtype=torch.bfloat16,
        reduce_dtype=torch.float32,   # AllReduce in FP32 for stability
        buffer_dtype=torch.bfloat16,
    )

    model = model_cls()
    model = FSDP(
        model,
        auto_wrap_policy=wrap_policy,
        mixed_precision=mp_policy,
        sharding_strategy=ShardingStrategy.FULL_SHARD,        # ZeRO-3 equivalent
        backward_prefetch=BackwardPrefetch.BACKWARD_PRE,      # overlap comms
        cpu_offload=CPUOffload(offload_params=False),         # set True to offload
        device_id=torch.cuda.current_device(),
        use_orig_params=True,    # required for torch.compile + optimizer groups
    )
    return model

def train():
    setup()
    from transformers import LlamaForCausalLM, LlamaConfig
    from transformers.models.llama.modeling_llama import LlamaDecoderLayer

    config = LlamaConfig(num_hidden_layers=32, hidden_size=4096, num_attention_heads=32)
    model  = build_fsdp_model(lambda: LlamaForCausalLM(config), LlamaDecoderLayer)

    # Activation checkpointing — trade compute for memory
    from torch.distributed.algorithms._checkpoint.checkpoint_wrapper import (
        apply_activation_checkpointing, checkpoint_wrapper, CheckpointImpl)
    check_fn = lambda m: isinstance(m, LlamaDecoderLayer)
    apply_activation_checkpointing(model, checkpoint_wrapper_fn=checkpoint_wrapper,
                                   check_fn=check_fn)

    optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.1)
    loader    = build_loader()

    for step, batch in enumerate(loader):
        optimizer.zero_grad()
        loss = model(**batch).loss
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        optimizer.step()

    # Save sharded checkpoint
    from torch.distributed.fsdp import StateDictType, FullStateDictConfig
    with FSDP.state_dict_type(model, StateDictType.FULL_STATE_DICT,
                               FullStateDictConfig(offload_to_cpu=True, rank0_only=True)):
        state = model.state_dict()
        if int(os.environ["RANK"]) == 0:
            torch.save(state, "model_final.pt")

6. Mixed Precision Training

FP3232±3.4×10³⁸Master weights, optimizer statesBaseline; memory-heavy

Why BF16 over FP16 for LLMs: BF16 has the same 8-bit exponent as FP32, so it can represent the same range. No overflow/underflow during training. No loss scaling needed. H100/A100 support BF16 at full tensor core throughput.

AMP Training with torch.autocast

import torch
from torch.cuda.amp import GradScaler

device = "cuda"
model  = MyModel().to(device)
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4)

# FP16 needs GradScaler to handle underflow; BF16 does not
use_fp16 = False  # Switch to True on V100/older GPUs without BF16
dtype    = torch.float16 if use_fp16 else torch.bfloat16
scaler   = GradScaler(enabled=use_fp16)

for batch in loader:
    x, y = batch
    x, y = x.to(device), y.to(device)

    optimizer.zero_grad(set_to_none=True)  # faster than zero_grad()

    # autocast casts ops to low precision automatically
    with torch.autocast(device_type="cuda", dtype=dtype):
        logits = model(x)
        loss   = criterion(logits, y)

    # scaler.scale is a no-op when enabled=False (BF16 path)
    scaler.scale(loss).backward()

    # Unscale before clipping so clip uses true gradient magnitudes
    scaler.unscale_(optimizer)
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

    scaler.step(optimizer)
    scaler.update()

7. Gradient Checkpointing & Flash Attention

Activations from forward pass are needed for backward. Without checkpointing, memory scales as O(n·L) (sequence × layers). With checkpointing, re-compute activations during backward — memory drops to O(√L) at cost of ~30% extra compute.

torch.utils.checkpoint

import torch.utils.checkpoint as ckpt

class TransformerBlock(nn.Module):
    def __init__(self, d_model, nhead):
        super().__init__()
        self.attn = nn.MultiheadAttention(d_model, nhead, batch_first=True)
        self.ffn  = nn.Sequential(nn.Linear(d_model, 4*d_model),
                                   nn.GELU(),
                                   nn.Linear(4*d_model, d_model))
        self.ln1  = nn.LayerNorm(d_model)
        self.ln2  = nn.LayerNorm(d_model)

    def _forward(self, x):
        x = x + self.attn(self.ln1(x), self.ln1(x), self.ln1(x))[0]
        x = x + self.ffn(self.ln2(x))
        return x

    def forward(self, x):
        # use_reentrant=False recommended for composability with FSDP/compile
        return ckpt.checkpoint(self._forward, x, use_reentrant=False)

# Memory optimization configuration — all together
def configure_memory_optimizations(model, use_flash=True, use_checkpointing=True):
    if use_flash:
        torch.backends.cuda.enable_flash_sdp(True)
        torch.backends.cuda.enable_mem_efficient_sdp(True)

    if use_checkpointing:
        model.gradient_checkpointing_enable(
            gradient_checkpointing_kwargs={"use_reentrant": False})

    torch.backends.cudnn.allow_tf32        = True
    torch.backends.cudnn.benchmark         = True   # auto-tune convolutions

    return model

"""
accelerate_train.py — works on 1 GPU, 8 GPUs, or 128 GPUs with zero code changes
Configure with: accelerate config
Launch with:    accelerate launch accelerate_train.py
"""
from accelerate import Accelerator
from transformers import AutoModelForCausalLM, AutoTokenizer, get_scheduler
import torch
from torch.utils.data import DataLoader

def train():
    accelerator = Accelerator(
        mixed_precision="bf16",        # "fp16" / "bf16" / "no"
        gradient_accumulation_steps=4,
        log_with="wandb",
        project_dir="./logs"
    )
    accelerator.init_trackers("my_llm_run", config={"lr": 1e-4})

    model     = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-2-7b-hf")
    tokenizer = AutoTokenizer.from_pretrained("meta-llama/Llama-2-7b-hf")
    optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4)
    loader    = DataLoader(MyDataset(tokenizer), batch_size=8, shuffle=True)
    scheduler = get_scheduler("cosine", optimizer, num_warmup_steps=100,
                              num_training_steps=len(loader) * 3)

    # prepare() handles DDP/FSDP wrapping, device placement, sampler replacement
    model, optimizer, loader, scheduler = accelerator.prepare(
        model, optimizer, loader, scheduler)

    for epoch in range(3):
        for step, batch in enumerate(loader):
            with accelerator.accumulate(model):   # handles grad accumulation
                outputs = model(**batch)
                loss    = outputs.loss
                accelerator.backward(loss)
                accelerator.clip_grad_norm_(model.parameters(), 1.0)
                optimizer.step()
                scheduler.step()
                optimizer.zero_grad()

            if step % 50 == 0:
                accelerator.log({"loss": loss.item()}, step=step)

    # Unwrap before saving
    unwrapped = accelerator.unwrap_model(model)
    accelerator.wait_for_everyone()
    if accelerator.is_main_process:
        unwrapped.save_pretrained("./output")

if __name__ == "__main__":
    train()

9. Efficient Data Loading

GPU utilization drops to 40-60% when data loading is the bottleneck. Key levers: num_workers, pin_memory, prefetch_factor, and streaming datasets for large corpora that don't fit on disk.

"""
data_pipeline.py — optimized distributed data loading
"""
import webdataset as wds
import torch
from torch.utils.data import DataLoader
from torch.utils.data.distributed import DistributedSampler

# ── Approach 1: Standard dataset with DistributedSampler ──────────────────
def make_standard_loader(dataset, rank, world_size, batch_size=32):
    sampler = DistributedSampler(
        dataset, num_replicas=world_size, rank=rank,
        shuffle=True, seed=42, drop_last=True)
    return DataLoader(
        dataset,
        batch_size=batch_size,
        sampler=sampler,
        num_workers=min(8, torch.multiprocessing.cpu_count() // 2),
        pin_memory=True,          # page-lock host memory for fast H2D transfer
        prefetch_factor=2,        # prefetch 2 batches per worker
        persistent_workers=True,  # keep workers alive across epochs
        drop_last=True,
    )

# ── Approach 2: WebDataset for streaming from S3/GCS/local tar files ──────
def make_webdataset_loader(urls, batch_size=32, world_size=1, rank=0):
    """
    urls: e.g., "s3://bucket/data/shard-{000000..001023}.tar"
    Each shard is a .tar file of (sample.txt, sample.json) pairs.
    """
    dataset = (
        wds.WebDataset(urls, resampled=True, shardshuffle=True)
          .shuffle(10000)          # buffer 10k samples
          .decode("torch")         # auto-decode images/tensors
          .to_tuple("input.pt", "label.pt")
          .batched(batch_size, partial=False)
    )

    # WebDataset handles distributed sharding via shard splitting
    loader = wds.WebLoader(dataset, batch_size=None, num_workers=4,
                           pin_memory=True, prefetch_factor=4)
    # Rebalance across ranks
    loader = loader.with_epoch(10000 // batch_size)
    return loader

# ── Approach 3: HuggingFace datasets with streaming ───────────────────────
from datasets import load_dataset, IterableDataset

Spot Instance Training with Auto-Resume

"""
spot_train.py — fault-tolerant training for AWS Spot / GCP Preemptible
Key: checkpoint every N steps; detect preemption via SIGTERM
"""
import signal, sys, os, time, torch

CKPT_DIR   = "/mnt/efs/checkpoints"
CKPT_EVERY = 500  # steps

class SpotTrainer:
    def __init__(self, model, optimizer, scheduler):
        self.model     = model
        self.optimizer = optimizer
        self.scheduler = scheduler
        self.step      = 0
        self._interrupted = False
        # Register SIGTERM handler (Spot interruption gives ~2 min warning)
        signal.signal(signal.SIGTERM, self._handle_sigterm)

    def _handle_sigterm(self, signum, frame):
        print(f"[Rank {os.environ.get('RANK',0)}] SIGTERM received — saving checkpoint")
        self._save(tag="preempted")
        self._interrupted = True

    def _save(self, tag="step"):
        if int(os.environ.get("RANK", 0)) != 0:
            return
        path = f"{CKPT_DIR}/ckpt_{tag}_{self.step}.pt"
        torch.save({
            "step":      self.step,
            "model":     self.model.state_dict(),
            "optimizer": self.optimizer.state_dict(),
            "scheduler": self.scheduler.state_dict(),
            "rng_state": torch.cuda.get_rng_state(),
        }, path + ".tmp")
        os.replace(path + ".tmp", path)   # atomic rename — no corrupt checkpoints
        print(f"Checkpoint saved: {path}")
        # Keep only last 3 checkpoints
        ckpts = sorted(f for f in os.listdir(CKPT_DIR) if f.startswith("ckpt_step"))
        for old in ckpts[:-3]:
            os.remove(os.path.join(CKPT_DIR, old))

    def load_latest(self):
        ckpts = sorted(f for f in os.listdir(CKPT_DIR) if f.endswith(".pt"))
        if not ckpts:
            return 0
        ckpt  = torch.load(os.path.join(CKPT_DIR, ckpts[-1]), map_location="cpu")
        self.model.load_state_dict(ckpt["model"])
        self.optimizer.load_state_dict(ckpt["optimizer"])
        self.scheduler.load_state_dict(ckpt["scheduler"])
        self.step = ckpt["step"]
        print(f"Resumed from step {self.step}")
        return self.step

    def train_loop(self, loader):
        self.load_latest()
        for batch in loader:
            if self._interrupted:
                sys.exit(0)
            # ... normal training step ...
            self.step += 1
            if self.step % CKPT_EVERY == 0:
                self._save(tag="step")

Training Cost Estimation

// Chinchilla scaling: FLOPs ≈ 6 × N × D (N=params, D=tokens)
FLOPS = 6 × 7e9 × 1e12 = 4.2 × 10²² FLOPs (7B model, 1T tokens)
A100 peak BF16: 312 TFLOP/s → at 40% MFU → ~125 TFLOP/s effective
GPU-hours = 4.2×10²² / (125×10¹²×3600) ≈ 93,333 A100-hours
512 A100s → 182 hours ≈ 7.6 days @ ~$2/hr → ~$186K
// MFU = (observed tokens/sec × 6N) / (GPUs × peak_flops)
Cost reduction levers: Use BF16 (2× vs FP32). Enable Flash Attention (1.5–3× throughput). Use Spot/Preemptible instances (60-80% discount). Pack sequences (remove padding). Use compiled model with torch.compile(model, mode="reduce-overhead"). Together these can reduce cost by 4-6×.

Key Takeaways

  • 1. Memory math first: 12×P bytes for full training (params + grads + Adam states). Know your budget before choosing a parallelism strategy.
  • 2. Start with DDP + ZeRO-2/3: Covers 90% of use cases up to ~70B params. Only add TP/PP for 100B+ where inter-GPU bandwidth is not the bottleneck.
  • 3. BF16 is the right default for training on A100/H100. FP16 requires loss scaling and overflows in long runs. FP8 is emerging for H100 pre-training.
  • 4. FSDP vs DeepSpeed: FSDP is native PyTorch and composes with torch.compile. DeepSpeed has ZeRO-Infinity (NVMe offload) for extreme memory constraints.
  • 5. Gradient checkpointing + Flash Attention together reduce memory by 8-10× with only ~30% compute overhead. Always enable both for long-context training.
  • 6. Data loading is frequently the bottleneck. Profile GPU utilization first. WebDataset + multiple workers nearly always fixes it.
  • 7. Checkpoint atomically. Write to .tmp, rename. Save every 500 steps on spot instances. SIGTERM gives you ~2 minutes on AWS.
  • 8. MFU (Model FLOP Utilization) is the right efficiency metric. Target >40% for DDP jobs, >35% for ZeRO-3. Below 30% means something is wrong — debug with torch.profiler.
