The RAG Architecture

Retrieval-Augmented Generation (RAG) combines the parametric knowledge of large language models with non-parametric, dynamic knowledge stores. The core insight is that LLMs have a knowledge cutoff and cannot reliably memorize factual details — but they excel at reasoning over provided context. RAG lets you separate concerns: the LLM handles language understanding and generation, while a retrieval system handles factual grounding.

Why RAG Wins for Knowledge-Intensive Tasks

Fine-tuning a model on your private documents costs thousands of dollars and takes days. It also bakes knowledge into weights — meaning it goes stale and is hard to audit. RAG externalizes knowledge: update your vector index and the system immediately knows the new fact. At Kimi we served 100M+ document tokens per day through a RAG layer, and the retrieval system was the highest-ROI investment we made.

Document Processing Pipeline

The quality of your RAG system is bounded by your document processing pipeline. Garbage in, garbage out — a perfectly tuned retrieval system cannot recover semantic information lost by a bad PDF parser. Document processing involves four stages: parsing (format-specific extraction), cleaning (removing boilerplate, artifacts), chunking (splitting into retrieval units), and enrichment (adding metadata that enables filtered retrieval).

class DocumentProcessor:
    """Production document processor with multi-format support."""

    LOADER_MAP = {
        ".pdf":  PyPDFLoader,
        ".html": UnstructuredHTMLLoader,
        ".htm":  UnstructuredHTMLLoader,
        ".docx": UnstructuredWordDocumentLoader,
        ".txt":  TextLoader,
        ".md":   TextLoader,
    }

    def __init__(
        self,
        chunk_size: int = 512,
        chunk_overlap: int = 64,
        strategy: str = "recursive",  # recursive | semantic | markdown
    ):
        self.chunk_size = chunk_size
        self.chunk_overlap = chunk_overlap
        self.strategy = strategy

        if strategy == "semantic":
            self.splitter = SemanticChunker(
                OpenAIEmbeddings(model="text-embedding-3-small"),
                breakpoint_threshold_type="percentile",
                breakpoint_threshold_amount=90,
            )
        elif strategy == "markdown":
            self.md_splitter = MarkdownHeaderTextSplitter(
                headers_to_split_on=[
                    ("#", "h1"), ("##", "h2"), ("###", "h3")
                ]
            )
            self.splitter = RecursiveCharacterTextSplitter(
                chunk_size=chunk_size, chunk_overlap=chunk_overlap
            )
        else:  # recursive (default, production workhorse)
            self.splitter = RecursiveCharacterTextSplitter(
                chunk_size=chunk_size,
                chunk_overlap=chunk_overlap,
                separators=["\n\n", "\n", ". ", " ", ""],
                length_function=len,
                is_separator_regex=False,
            )

    def load_file(self, path: str) -> List[Document]:
        """Load a single file using the appropriate loader."""
        ext = Path(path).suffix.lower()
        loader_cls = self.LOADER_MAP.get(ext)
        if not loader_cls:
            raise ValueError(f"Unsupported file type: {ext}")
        loader = loader_cls(path)
        return loader.load()

    def compute_doc_hash(self, content: str) -> str:
        return hashlib.sha256(content.encode()).hexdigest()[:16]

    def enrich_metadata(self, doc: Document, source_path: str) -> Document:
        """Add content hash, word count, and source metadata."""
        doc.metadata["doc_id"]     = self.compute_doc_hash(doc.page_content)
        doc.metadata["char_count"] = len(doc.page_content)
        doc.metadata["word_count"] = len(doc.page_content.split())
        doc.metadata["source"]     = source_path
        doc.metadata["file_type"]  = Path(source_path).suffix.lower()
        return doc

    def process_file(self, path: str) -> List[Document]:
        """Full pipeline: load → chunk → enrich."""
        raw_docs = self.load_file(path)
        if self.strategy == "markdown" and path.endswith(".md"):
            chunks = []
            for doc in raw_docs:
                md_chunks = self.md_splitter.split_text(doc.page_content)
                chunks.extend(self.splitter.split_documents(md_chunks))
        else:
            chunks = self.splitter.split_documents(raw_docs)

        return [self.enrich_metadata(c, path) for c in chunks]

    def process_directory(self, directory: str, glob: str = "**/*") -> List[Document]:
        """Recursively process all supported files in a directory."""
        all_chunks = []
        p = Path(directory)
        for ext in self.LOADER_MAP.keys():
            for file_path in p.glob(f"**/*{ext}"):
                try:
                    chunks = self.process_file(str(file_path))
                    all_chunks.extend(chunks)
                    print(f"  Processed {file_path}: {len(chunks)} chunks")
                except Exception as e:
                    print(f"  ERROR {file_path}: {e}")
        return all_chunks

def process_pdf_advanced(

    extract_images: bool = True,
    extract_tables: bool = True,
    hi_res: bool = True,
) -> List[Document]:
    """
    Process PDF with layout analysis.
    hi_res=True uses detectron2 for table/figure detection.
    """
    strategy = "hi_res" if hi_res else "fast"

    elements = partition_pdf(
        filename=pdf_path,

        extract_images_in_pdf=extract_images,
        extract_image_block_output_dir="./extracted_images",

        new_after_n_chars=800,
        combine_text_under_n_chars=100,
    )

    docs = []
    for elem in elements:
        metadata = {
            "source": pdf_path,
            "element_type": type(elem).__name__,
            "page_number": elem.metadata.page_number if elem.metadata else None,
            "filename": elem.metadata.filename if elem.metadata else None,
        }

        if isinstance(elem, Table):
            # Convert table to markdown for better LLM comprehension
            content = f"[TABLE]\n{elem.metadata.text_as_html}\n[/TABLE]"
            metadata["is_table"] = True
        elif isinstance(elem, Image):
            content = f"[IMAGE: {elem.text}]"
            metadata["is_image"] = True
        else:
            content = elem.text

        if content and len(content.strip()) > 20:
            docs.append(Document(page_content=content.strip(), metadata=metadata))

    return docs

Batch Embedding Generation (Efficient)

batch_embedder.py 
import asyncio
import time
from typing import List, Optional
import numpy as np
from openai import AsyncOpenAI
from tenacity import retry, stop_after_attempt, wait_exponential
import tiktoken


class BatchEmbedder:
    """
    Efficient batch embedding with rate-limit handling, retry logic,
    and Matryoshka dimension reduction.
    """
    MAX_BATCH_TOKENS = 300_000   # OpenAI API limit per request
    MAX_BATCH_ITEMS  = 2048      # OpenAI limit per batch call

    def __init__(
        self,
        model: str = "text-embedding-3-large",
        dimensions: Optional[int] = None,  # Matryoshka reduction
        max_concurrent: int = 20,
    ):
        self.client = AsyncOpenAI()
        self.model = model
        self.dimensions = dimensions  # e.g., 256 for cost savings
        self.semaphore = asyncio.Semaphore(max_concurrent)
        self.enc = tiktoken.get_encoding("cl100k_base")

    def count_tokens(self, text: str) -> int:
        return len(self.enc.encode(text, disallowed_special=()))

    def build_batches(self, texts: List[str]) -> List[List[str]]:
        """Group texts into batches respecting token and item limits."""
        batches, current_batch, current_tokens = [], [], 0
        for text in texts:
            tokens = self.count_tokens(text)
            if tokens > 8191:  # truncate to model max
                text = self.enc.decode(self.enc.encode(text)[:8191])
                tokens = 8191
            if (current_tokens + tokens > self.MAX_BATCH_TOKENS or
                    len(current_batch) >= self.MAX_BATCH_ITEMS):
                batches.append(current_batch)
                current_batch, current_tokens = [], 0
            current_batch.append(text)
            current_tokens += tokens
        if current_batch:
            batches.append(current_batch)
        return batches

    @retry(stop=stop_after_attempt(5),
           wait=wait_exponential(multiplier=1, min=2, max=60))
    async def _embed_batch(self, texts: List[str]) -> List[List[float]]:
        async with self.semaphore:
            kwargs = {"model": self.model, "input": texts}
            if self.dimensions:
                kwargs["dimensions"] = self.dimensions
            resp = await self.client.embeddings.create(**kwargs)
            return [item.embedding for item in resp.data]

    async def embed_async(self, texts: List[str]) -> np.ndarray:
        batches = self.build_batches(texts)
        tasks = [self._embed_batch(batch) for batch in batches]
        results = await asyncio.gather(*tasks)
        all_embeddings = [emb for batch in results for emb in batch]
        return np.array(all_embeddings, dtype=np.float32)

    def embed(self, texts: List[str]) -> np.ndarray:
        """Synchronous wrapper."""
        return asyncio.run(self.embed_async(texts))

    def embed_with_stats(self, texts: List[str]) -> dict:
        start = time.time()
        embeddings = self.embed(texts)
        elapsed = time.time() - start
        return {
            "embeddings":  embeddings,
            "shape":       embeddings.shape,
            "elapsed_s":   round(elapsed, 2),
            "docs_per_sec": round(len(texts) / elapsed, 1),
        }

from sentence_transformers import SentenceTransformer, InputExample, losses
from torch.utils.data import DataLoader

def finetune_embedding_model(
    base_model: str,
    train_pairs: List[dict],  # [{"query": ..., "positive": ..., "negative": ...}]
    output_dir: str,
    epochs: int = 3,
):
    model = SentenceTransformer(base_model)
    examples = [
        InputExample(texts=[p["query"], p["positive"]], label=1.0)
        for p in train_pairs
    ]
    loader = DataLoader(examples, shuffle=True, batch_size=32)
    loss = losses.MultipleNegativesRankingLoss(model)
    model.fit(
        train_objectives=[(loader, loss)],
        epochs=epochs,
        warmup_steps=100,
        output_path=output_dir,
        show_progress_bar=True,
    )
    print(f"Fine-tuned model saved to {output_dir}")

Matryoshka Embeddings

OpenAI's text-embedding-3 models support Matryoshka Representation Learning (MRL). You can truncate from 3072 down to 256 dimensions and lose only ~3% MTEB accuracy while cutting storage by 12x and ANN search by 4x. For a 10M-document corpus this is the difference between 115GB and 9.6GB of index. Always use this in production unless you need maximum recall.

Qdrant: Collection Setup and Hybrid Search

qdrant_setup.py 
from qdrant_client import QdrantClient
from qdrant_client.models import (
    VectorParams, Distance, HnswConfigDiff,
    SparseVectorParams, SparseIndexParams,
    PointStruct, SparseVector,
    NamedVector, NamedSparseVector,
    SearchRequest, Filter, FieldCondition, MatchValue, Range,
)
from typing import List, Dict, Any
import numpy as np


class QdrantVectorStore:
    """Production Qdrant vector store with hybrid dense+sparse search."""

    COLLECTION = "knowledge_base"

    def __init__(self, url: str = "http://localhost:6333", api_key: str = None):
        self.client = QdrantClient(url=url, api_key=api_key)
        self._ensure_collection()

    def _ensure_collection(self):
        existing = [c.name for c in self.client.get_collections().collections]
        if self.COLLECTION not in existing:
            self.client.create_collection(
                collection_name=self.COLLECTION,
                vectors_config={
                    "dense": VectorParams(
                        size=1536,
                        distance=Distance.COSINE,
                        hnsw_config=HnswConfigDiff(
                            m=16,                 # edges per node (16-48)
                            ef_construct=200,     # build-time accuracy (100-400)
                            full_scan_threshold=10_000,
                        ),
                    )
                },
                sparse_vectors_config={
                    "sparse": SparseVectorParams(
                        index=SparseIndexParams(on_disk=False)
                    )
                },
            )
            print(f"Created collection '{self.COLLECTION}'")

    def upsert(
        self,
        ids: List[str],
        dense_vectors: np.ndarray,
        sparse_indices: List[List[int]],
        sparse_values: List[List[float]],
        payloads: List[Dict[str, Any]],
    ):
        """Batch upsert dense + sparse vectors."""
        points = [
            PointStruct(
                id=str(i),
                vector={
                    "dense": dense_vectors[idx].tolist(),
                    "sparse": SparseVector(
                        indices=sparse_indices[idx],
                        values=sparse_values[idx],
                    ),
                },
                payload=payloads[idx],
            )
            for idx, i in enumerate(ids)
        ]
        # Batch in chunks of 100 for stability
        for i in range(0, len(points), 100):
            self.client.upsert(
                collection_name=self.COLLECTION,
                points=points[i:i+100],
            )

    def hybrid_search(
        self,
        dense_vector: List[float],
        sparse_indices: List[int],
        sparse_values: List[float],
        top_k: int = 20,
        filter_dict: Dict[str, Any] = None,
        rrf_k: int = 60,
    ) -> List[Dict]:
        """
        Hybrid search: dense + sparse with Reciprocal Rank Fusion.
        rrf_k=60 is standard RRF constant.
        """
        qdrant_filter = None
        if filter_dict:
            conditions = []
            for key, val in filter_dict.items():
                if isinstance(val, (str, bool)):
                    conditions.append(FieldCondition(key=key, match=MatchValue(value=val)))
                elif isinstance(val, dict) and "gte" in val:
                    conditions.append(FieldCondition(key=key, range=Range(**val)))
            qdrant_filter = Filter(must=conditions) if conditions else None

        results = self.client.query_points(
            collection_name=self.COLLECTION,
            prefetch=[
                # Dense vector search
                {"query": dense_vector,   "using": "dense",  "limit": top_k},
                # Sparse vector search (BM25-like)
                {"query": SparseVector(indices=sparse_indices, values=sparse_values),
                 "using": "sparse", "limit": top_k},
            ],
            query={"fusion": "rrf"},   # Reciprocal Rank Fusion
            limit=top_k,
            query_filter=qdrant_filter,
            with_payload=True,
        ).points

        return [
            {"id": r.id, "score": r.score, **r.payload}
            for r in results
        ]

Pre-filtering vs Post-filtering

When you filter by metadata (e.g., tenant_id, date), pre-filtering (filter before ANN search) is safer but can miss relevant results if the filtered corpus is small. Post-filtering (search globally, then filter) risks returning fewer than top-k results. Qdrant's filtered HNSW solves this with segment-level pre-filtering. Pinecone uses metadata-aware index sharding. Always test your filter coverage ratio — if filtering eliminates more than 80% of the corpus, you need segment-level indices.

Retrieval Optimization

Naive top-k dense retrieval has a fundamental problem: a single query vector collapses all query intent into one point. Queries like "Why did our Q3 revenue drop?" have multiple sub-intents (financial data, business context, comparison to prior year). Dense retrieval will fetch the nearest neighbors to the average embedding, often missing the most relevant documents on any single intent. The solution is a stack of complementary retrieval strategies.

from rank_bm25 import BM25Okapi
from langchain.schema import Document
import numpy as np
from typing import List, Tuple


class HybridRetriever:
    """
    Hybrid BM25 + dense vector retrieval with Reciprocal Rank Fusion.
    RRF formula: score(d) = sum(1 / (k + rank(d)))
    """

    def __init__(
        self,
        documents: List[Document],
        embedder,           # any embed(texts) -> np.ndarray callable
        vector_store,       # any similarity_search_with_score callable
        alpha: float = 0.5, # 0 = BM25 only, 1 = dense only
        rrf_k: int = 60,
    ):
        self.documents = documents
        self.embedder = embedder
        self.vector_store = vector_store
        self.alpha = alpha
        self.rrf_k = rrf_k

        # Build BM25 index
        tokenized = [doc.page_content.lower().split() for doc in documents]
        self.bm25 = BM25Okapi(tokenized)

    def bm25_search(self, query: str, top_k: int) -> List[Tuple[Document, float]]:
        tokens = query.lower().split()
        scores = self.bm25.get_scores(tokens)
        top_indices = np.argsort(scores)[::-1][:top_k]
        return [(self.documents[i], float(scores[i])) for i in top_indices]

    def reciprocal_rank_fusion(
        self,
        bm25_results: List[Tuple[Document, float]],
        dense_results: List[Tuple[Document, float]],
        top_k: int,
    ) -> List[Tuple[Document, float]]:
        """Merge ranked lists using RRF. Handles duplicate documents by doc_id."""
        scores: dict = {}
        id_to_doc: dict = {}

        for rank, (doc, _) in enumerate(bm25_results):
            doc_id = doc.metadata.get("doc_id", doc.page_content[:50])
            scores[doc_id] = scores.get(doc_id, 0) + (1 - self.alpha) / (self.rrf_k + rank)
            id_to_doc[doc_id] = doc

        for rank, (doc, _) in enumerate(dense_results):
            doc_id = doc.metadata.get("doc_id", doc.page_content[:50])
            scores[doc_id] = scores.get(doc_id, 0) + self.alpha / (self.rrf_k + rank)
            id_to_doc[doc_id] = doc

        sorted_ids = sorted(scores, key=scores.__getitem__, reverse=True)[:top_k]
        return [(id_to_doc[i], scores[i]) for i in sorted_ids]

    def retrieve(self, query: str, top_k: int = 10) -> List[Document]:
        bm25_results = self.bm25_search(query, top_k * 2)
        dense_results = self.vector_store.similarity_search_with_score(query, k=top_k * 2)
        fused = self.reciprocal_rank_fusion(bm25_results, dense_results, top_k)
        return [doc for doc, _ in fused]

class LocalReranker:
    """BGE-Reranker-v2-m3 — self-hosted, multilingual, ~200MB."""

    def __init__(self, model_name: str = "BAAI/bge-reranker-v2-m3"):
        self.model = CrossEncoder(model_name, max_length=512)

    def rerank(
        self,
        query: str,
        documents: List[Document],
        top_n: int = 5,
    ) -> List[Document]:
        pairs = [(query, doc.page_content) for doc in documents]
        scores = self.model.predict(pairs, batch_size=32)
        ranked = sorted(zip(documents, scores), key=lambda x: x[1], reverse=True)
        for doc, score in ranked[:top_n]:
            doc.metadata["rerank_score"] = float(score)
        return [doc for doc, _ in ranked[:top_n]]


class HyDERetriever:

    HyDE: Hypothetical Document Embeddings.
    LLM generates a hypothetical answer, then that answer's embedding
    is used for retrieval. Works well for abstract/research queries.
    """

    def __init__(self, llm, vector_store, embedder):
        self.llm = llm
        self.vector_store = vector_store
        self.embedder = embedder

    def generate_hypothetical_doc(self, query: str) -> str:
        prompt = f"""Write a short passage (2-3 sentences) that would be a
perfect answer to this question. Be specific and factual.

Question: {query}

Passage:"""
        return self.llm.invoke(prompt).content

    def retrieve(self, query: str, top_k: int = 10) -> List[Document]:
        # Generate hypothetical answer
        hyp_doc = self.generate_hypothetical_doc(query)
        # Embed the hypothetical doc (not the query)
        hyp_embedding = self.embedder.embed([hyp_doc])[0]
        # Search using hypothetical doc embedding
        return self.vector_store.similarity_search_by_vector(hyp_embedding, k=top_k)

RAPTOR: Recursive Abstractive Processing

RAPTOR builds a tree of summaries over your document corpus. Leaf nodes are raw chunks; each parent is an LLM-generated summary of its children. At query time, you search across all tree levels. This is expensive to build (O(n log n) LLM calls) but dramatically improves multi-hop question answering — ideal for large technical manuals and legal codebases. LlamaIndex has a native RAPTOR implementation.

def format_context(docs: List[Document]) -> str:
    """Format retrieved docs into numbered context block with source metadata."""
    parts = []
    for i, doc in enumerate(docs, 1):
        source = doc.metadata.get("source", "unknown")
        page   = doc.metadata.get("page_number", "")
        page_str = f", page {page}" if page else ""
        parts.append(f"[Source {i}] ({source}{page_str})\n{doc.page_content}")
    return "\n\n---\n\n".join(parts)


def extract_sources(docs: List[Document]) -> List[dict]:

            "source":  d.metadata.get("source", ""),
            "page":    d.metadata.get("page_number"),
            "score":   d.metadata.get("rerank_score"),

class ProductionRAG:
    def __init__(
        self,
        qdrant_url: str,
        qdrant_api_key: str,
        collection_name: str,
        openai_api_key: str,
        reranker=None,       # Optional reranker instance
        top_k: int = 20,
        top_n: int = 5,
        stream: bool = True,
    ):
        # Embedding model
        self.embeddings = OpenAIEmbeddings(
            model="text-embedding-3-large",
            dimensions=1536,
            openai_api_key=openai_api_key,
        )

        # Vector store
        self.vectorstore = QdrantVectorStore.from_existing_collection(
            embedding=self.embeddings,
            url=qdrant_url,
            api_key=qdrant_api_key,
            collection_name=collection_name,
        )

        # Retriever with generous top_k (reranker will narrow down)
        self.base_retriever = self.vectorstore.as_retriever(
            search_type="similarity",
            search_kwargs={"k": top_k},
        )

        self.reranker = reranker
        self.top_n = top_n

        # Generation LLM
        self.llm = ChatOpenAI(
            model="gpt-4o",
            temperature=0,
            streaming=stream,
            openai_api_key=openai_api_key,
        )

        # Contextualization LLM (cheap model for query reformulation)
        self.ctx_llm = ChatOpenAI(
            model="gpt-4o-mini",
            temperature=0,
            openai_api_key=openai_api_key,
        )

        # Memory
        self.memory = ConversationBufferWindowMemory(
            k=6, return_messages=True, memory_key="history"
        )

        self._build_chain()

    def _retrieve_and_rerank(self, query: str) -> List[Document]:
        docs = self.base_retriever.invoke(query)
        if self.reranker and docs:
            docs = self.reranker.rerank(query, docs, top_n=self.top_n)
        return docs[:self.top_n]

    def _contextualize_query(self, inputs: dict) -> str:
        history = self.memory.load_memory_variables({})["history"]
        if not history:
            return inputs["question"]
        history_str = "\n".join(
            f"{'Human' if isinstance(m, HumanMessage) else 'AI'}: {m.content}"
            for m in history
        )
        prompt = CONTEXTUALIZE_PROMPT.format(
            history=history_str, question=inputs["question"]
        )
        return self.ctx_llm.invoke(prompt).content

    def _build_chain(self):
        rag_prompt = ChatPromptTemplate.from_messages([
            ("system", RAG_SYSTEM_PROMPT),
            MessagesPlaceholder(variable_name="history"),
            ("human", "{question}"),
        ])

        retrieve = RunnableLambda(
            lambda x: self._retrieve_and_rerank(x["standalone_question"])
        )

        self.chain = (
            RunnablePassthrough.assign(
                standalone_question=RunnableLambda(self._contextualize_query)
            )
            | RunnablePassthrough.assign(docs=retrieve)
            | RunnablePassthrough.assign(
                context=lambda x: format_context(x["docs"]),
                history=lambda _: self.memory.load_memory_variables({})["history"],
            )
            | RunnableParallel(
                answer=rag_prompt | self.llm | StrOutputParser(),
                sources=lambda x: extract_sources(x["docs"]),
            )
        )

    def query(self, question: str) -> dict:
        """Single query with source attribution."""
        result = self.chain.invoke({"question": question})
        # Save to memory
        self.memory.save_context(
            {"input": question}, {"output": result["answer"]}
        )
        return result

    def stream(self, question: str) -> Iterator[str]:
        """Streaming response — yields answer tokens."""
        inputs = {"question": question}
        standalone = self._contextualize_query(inputs)
        docs = self._retrieve_and_rerank(standalone)
        context = format_context(docs)
        history = self.memory.load_memory_variables({})["history"]

        prompt = ChatPromptTemplate.from_messages([
            ("system", RAG_SYSTEM_PROMPT),
            MessagesPlaceholder(variable_name="history"),
            ("human", "{question}"),
        ])
        chain = prompt | self.llm | StrOutputParser()

        full_response = ""
        for chunk in chain.stream({
            "context": context,
            "history": history,
            "question": question,
        }):
            full_response += chunk
            yield chunk

        self.memory.save_context({"input": question}, {"output": full_response})
        return extract_sources(docs)

An LLM agent is a system that uses a language model to decide which actions to take, executes those actions (calling tools, APIs, or other models), observes the results, and iterates until the task is complete. The key difference from a RAG chain is the feedback loop: agents can self-correct, multi-step, and handle unexpected outcomes. The dominant pattern is ReAct (Reasoning + Acting).

class ReActAgent:
    def __init__(
        self,
        system_prompt: str,
        max_iterations: int = 10,
        persistent_memory: list = None,
    ):
        self.system_prompt = system_prompt
        self.max_iterations = max_iterations
        self.messages = []
        # Persistent memory: inject prior facts at start
        if persistent_memory:
            self.messages.append({
                "role": "user",
                "content": f"Background context from memory:\n{json.dumps(persistent_memory)}"
            })
            self.messages.append({"role": "assistant", "content": "Understood."})

    def _execute_tool(self, tool_name: str, tool_input: dict) -> str:
        fn = TOOL_REGISTRY.get(tool_name)
        if not fn:
            return f"ERROR: Unknown tool '{tool_name}'"
        try:
            return fn(**tool_input)
        except Exception as e:
            return f"ERROR: Tool execution failed: {str(e)}"

    def run(self, user_message: str) -> str:
        self.messages.append({"role": "user", "content": user_message})

        for iteration in range(self.max_iterations):
            response = client.messages.create(
                model=MODEL,
                max_tokens=4096,
                system=self.system_prompt,
                tools=TOOLS,
                messages=self.messages,
            )

            # Append assistant response
            self.messages.append({"role": "assistant", "content": response.content})

            if response.stop_reason == "end_turn":
                # Extract text response
                for block in response.content:
                    if hasattr(block, "text"):
                        return block.text
                return "Task complete."

            if response.stop_reason == "tool_use":
                tool_results = []
                for block in response.content:
                    if block.type == "tool_use":
                        print(f"  [Tool] {block.name}({json.dumps(block.input)[:80]})")
                        result = self._execute_tool(block.name, block.input)
                        print(f"  [Result] {result[:80]}...")
                        tool_results.append({
                            "type": "tool_result",
                            "tool_use_id": block.id,
                            "content": result,
                        })
                self.messages.append({"role": "user", "content": tool_results})

        return "Max iterations reached. Partial result returned."

        "research": "research",
        "analyze":  "analysis",

    workflow.add_edge("writer",   END)

Multi-Agent Failure Modes

The most common production failures in multi-agent systems: (1) Infinite loops — always set max_iterations and a hard token budget. (2) Context explosion — each agent passing full history; use summarization at handoff boundaries. (3) Tool call storms — agents calling the same expensive API in parallel; implement rate limiting at the tool layer. (4) Silent failures — an agent returning empty output and the system treating it as success; validate outputs at every node.

"""
Incremental index update pipeline.
Only re-indexes changed documents using content hashing.
Handles deletes and updates correctly.
"""
import asyncio
import hashlib
import json
from datetime import datetime
from typing import List, Dict
import aiofiles
import aioboto3
from qdrant_client import AsyncQdrantClient
from qdrant_client.models import PointStruct, PointIdsList


class IncrementalIndexer:
    """
    Tracks document hashes in a state store.
    Only processes documents whose content has changed.
    """

    def __init__(
        self,
        qdrant_url: str,
        collection: str,
        state_store_path: str = "./index_state.json",
        batch_size: int = 50,
    ):
        self.qdrant = AsyncQdrantClient(url=qdrant_url)
        self.collection = collection
        self.state_path = state_store_path
        self.batch_size = batch_size
        self.state: Dict[str, str] = {}  # doc_path → content_hash

    async def load_state(self):
        try:
            async with aiofiles.open(self.state_path, 'r') as f:
                self.state = json.loads(await f.read())
        except FileNotFoundError:
            self.state = {}

    async def save_state(self):
        async with aiofiles.open(self.state_path, 'w') as f:
            await f.write(json.dumps(self.state, indent=2))

    def hash_content(self, content: str) -> str:
        return hashlib.sha256(content.encode()).hexdigest()[:16]

    async def detect_changes(self, documents: List[Dict]) -> Dict[str, List]:
        """Classify documents as new, updated, or deleted."""
        current_paths = {d["path"]: self.hash_content(d["content"]) for d in documents}
        result = {"new": [], "updated": [], "deleted": [], "unchanged": []}

        for doc in documents:
            path = doc["path"]
            new_hash = current_paths[path]
            old_hash = self.state.get(path)

            if old_hash is None:
                result["new"].append(doc)
            elif old_hash != new_hash:
                result["updated"].append(doc)
            else:
                result["unchanged"].append(doc)

        # Detect deletes: paths in state but not in current
        for path in self.state:
            if path not in current_paths:
                result["deleted"].append({"path": path, "doc_id": self.state[path]})

        return result

    async def index_batch(self, docs: List[Dict], embedder, processor):
        """Process and index a batch of documents."""
        all_chunks = []
        for doc in docs:
            chunks = processor.process_content(doc["content"], doc["path"])
            all_chunks.extend(chunks)

        if not all_chunks:
            return

        # Batch embed
        texts = [c["content"] for c in all_chunks]
        embeddings = await embedder.embed_async(texts)

        # Upsert to Qdrant
        points = [
            PointStruct(
                id=chunk["chunk_id"],
                vector=embeddings[i].tolist(),
                payload={
                    "content":   chunk["content"],
                    "source":    chunk["source"],
                    "chunk_idx": chunk["chunk_idx"],
                    "indexed_at": datetime.utcnow().isoformat(),
                    **chunk.get("metadata", {}),
                },
            )
            for i, chunk in enumerate(all_chunks)
        ]
        await self.qdrant.upsert(collection_name=self.collection, points=points)

    async def delete_doc_chunks(self, doc_path: str):
        """Delete all chunks belonging to a document."""
        await self.qdrant.delete(
            collection_name=self.collection,
            points_selector={"filter": {"must": [
                {"key": "source", "match": {"value": doc_path}}
            ]}},
        )

    async def run(self, documents: List[Dict], embedder, processor):
        await self.load_state()
        changes = await self.detect_changes(documents)

        print(f"Changes: +{len(changes['new'])} new, "
              f"~{len(changes['updated'])} updated, "
              f"-{len(changes['deleted'])} deleted, "
              f"={len(changes['unchanged'])} unchanged")

        # Delete removed documents
        for doc in changes["deleted"]:
            await self.delete_doc_chunks(doc["path"])
            del self.state[doc["path"]]

        # Re-index updated (delete old chunks first)
        for doc in changes["updated"]:
            await self.delete_doc_chunks(doc["path"])

        # Index new + updated in batches
        to_index = changes["new"] + changes["updated"]
        for i in range(0, len(to_index), self.batch_size):
            batch = to_index[i:i + self.batch_size]
            await self.index_batch(batch, embedder, processor)
            for doc in batch:
                self.state[doc["path"]] = self.hash_content(doc["content"])
            print(f"  Indexed batch {i//self.batch_size + 1}")

        await self.save_state()
        print("Incremental indexing complete.")

        "answer_relevancy": results["answer_relevancy"],
        "context_precision": results["context_precision"],
        "context_recall":   results["context_recall"],
        "timestamp":        datetime.utcnow().isoformat(),
    }

    with open(output_path, "w") as f:
        json.dump(scores, f, indent=2)

    print("\n=== RAGAS Evaluation Results ===")
    for metric, score in scores.items():
        if isinstance(score, float):
            status = "PASS" if score >= 0.7 else "WARN" if score >= 0.5 else "FAIL"
            print(f"  {metric:25s}: {score:.3f}  [{status}]")

    return scores

Sampling Strategy for Cost Control

Running RAGAS on every query is expensive (~$0.01/query). Use a tiered approach: log 100% of traces (cheap), run automated RAGAS evaluation on 5% random sample daily, run full evaluation weekly on your golden dataset. Use statistical process control (control charts) to detect metric drift — a 3-sigma deviation should trigger a full evaluation run and deployment gate.

access_controlled_retrieval.py 
"""
Access-controlled RAG retrieval.
User's identity claims (from JWT/OAuth) are used to build
Qdrant filters — ensuring strict data isolation without
separate vector indices per tenant.
"""
from dataclasses import dataclass
from typing import List, Set, Optional
from qdrant_client import QdrantClient
from qdrant_client.models import (
    Filter, FieldCondition, MatchAny, MatchValue, Range
)
import jwt


@dataclass
class UserContext:
    user_id:      str
    tenant_id:    str
    departments:  Set[str]     # e.g., {"HR", "Engineering"}
    clearance:    int          # 0=public, 1=internal, 2=confidential, 3=restricted
    regions:      Set[str]     # e.g., {"US", "EMEA"}


def decode_user_context(jwt_token: str, public_key: str) -> UserContext:
    """Extract user access claims from verified JWT."""
    claims = jwt.decode(jwt_token, public_key, algorithms=["RS256"])
    return UserContext(
        user_id=claims["sub"],
        tenant_id=claims["tenant_id"],
        departments=set(claims.get("departments", [])),
        clearance=int(claims.get("clearance_level", 0)),
        regions=set(claims.get("regions", ["US"])),
    )


def build_access_filter(user: UserContext) -> Filter:
    """
    Build Qdrant filter that enforces access control.
    A document is accessible if:
    1. tenant_id matches
    2. clearance_level <= user's clearance
    3. department is in user's allowed departments (or is "All")
    4. region is in user's allowed regions (or is "Global")
    """
    return Filter(
        must=[
            # Tenant isolation — hard boundary
            FieldCondition(
                key="tenant_id",
                match=MatchValue(value=user.tenant_id),
            ),
            # Clearance level: only return docs at or below user's clearance
            FieldCondition(
                key="clearance_level",
                range=Range(lte=user.clearance),
            ),
        ],
        should=[
            # Department: accessible if doc is in user's departments or marked "All"
            FieldCondition(
                key="department",
                match=MatchAny(any=list(user.departments) + ["All"]),
            ),
        ],
        minimum_should_match=1,
    )


class AccessControlledRetriever:
    def __init__(self, client: QdrantClient, collection: str, embedder):
        self.client = client
        self.collection = collection
        self.embedder = embedder

    def retrieve(
        self,
        query: str,
        user: UserContext,
        top_k: int = 10,
    ) -> List[dict]:
        # Embed query
        query_vector = self.embedder.embed([query])[0].tolist()

        # Build access filter from user's verified identity
        access_filter = build_access_filter(user)

        results = self.client.search(
            collection_name=self.collection,
            query_vector=query_vector,
            query_filter=access_filter,
            limit=top_k,
            with_payload=True,
        )

        # Audit log: every retrieval is logged with user_id + doc_ids
        self._audit_log(user.user_id, query, [r.id for r in results])

        return [{"id": r.id, "score": r.score, **r.payload} for r in results]

    def _audit_log(self, user_id: str, query: str, doc_ids: List):
        """Write to immutable audit store (append-only S3 + Athena)."""
        import json, time
        record = {
            "timestamp": time.time(),
            "user_id":   user_id,
            "query":     query[:200],  # truncate for privacy
            "doc_ids":   doc_ids,
        }
        # In production: write to Kinesis → S3 → Athena
        print(f"[AUDIT] {json.dumps(record)}")

- "knowledge": needs internal documents or policies
- "structured": needs numbers, metrics, or database data
- "direct": general knowledge, no internal docs needed
- "action": user wants to take an action (send, create, update)

Query: {query}

def route_query(query: str, llm) -> str:
    response = llm.invoke(QUERY_ROUTING_PROMPT.format(query=query))
    category = response.content.strip().lower()
    return category if category in {"knowledge", "structured", "direct", "action"} else "knowledge"

Lessons Learned at Scale

The hardest problem was not retrieval quality — it was keeping the index fresh. Documents change daily across SharePoint, Confluence, and Salesforce. Chapter 19 Key Takeaways

RAG Fundamentals

  • RAG separates knowledge storage (retrieval) from language understanding (generation)
  • Hybrid search (BM25 + dense) outperforms either alone — always use it in production
  • Reranking is the highest-ROI optimization per latency dollar spent

  • Chunk strategy matters: parent-child for precision, RAPTOR for multi-hop

Agent Systems

  • ReAct (observe-think-act) is the foundation of all production agents
  • LangGraph provides typed state machines — prevents infinite loops and context explosion
  • Human-in-the-loop is mandatory for any agent that takes real-world actions
  • Multi-agent systems decompose complexity but multiply failure modes
  • Always set max_iterations, token budgets, and tool rate limits

Production Engineering

  • Semantic caching eliminates 30-40% of LLM costs at scale
  • Incremental indexing with content hashing keeps indices fresh without full rebuilds
  • Access control bugs are silent and catastrophic — test with adversarial users
  • Query routing (RAG vs SQL vs direct) reduces cost and latency for 20-30% of queries
  • LangSmith or Langfuse from day one — you cannot optimize what you cannot trace

Evaluation

  • RAGAS provides four essential metrics: faithfulness, relevancy, precision, recall
  • Build a golden evaluation dataset before you start optimizing — you need a baseline
  • Integrate RAGAS into CI/CD as a deployment gate
  • Human evaluation for hallucination detection cannot be fully automated
  • Track cost per query as a first-class metric alongside quality
