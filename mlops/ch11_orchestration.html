1. Why Workflow Orchestration for ML

Foundation

A production ML system is not a single script — it is a graph of interdependent steps: data ingestion, validation, feature engineering, training, evaluation, registration, and deployment. Each step can fail. Some steps should only run if upstream steps succeeded. Some need to run on a schedule; others need to react to data events. Workflow orchestration is the discipline of defining, scheduling, executing, and monitoring these pipelines reliably.

Without an orchestrator, teams use cron jobs, shell scripts, and ad-hoc retry logic. This works until it doesn't — and in ML, undetected failures mean stale models in production. At Airbnb, every ML pipeline that ships to production runs through Airflow (or a managed equivalent). The orchestrator is the single pane of glass for pipeline health.

Core Requirements

  • Dependency management: Task B must not run until Task A succeeds.
  • Scheduling: Daily retraining, hourly feature refresh, weekly evaluation.
  • Retries and backoff: Transient failures (network, quota) should not page on-call.
  • Observability: Which tasks ran, how long they took, what failed and why.
  • Backfilling: Re-run historical pipeline runs when logic changes.
  • Parameterization: Same DAG logic, different datasets or hyperparameters.

DAG = Directed Acyclic Graph. All major orchestrators model pipelines as DAGs — nodes are tasks, edges are dependencies. The acyclic constraint ensures pipelines always terminate (no infinite loops).

2. Apache Airflow Architecture

Core Technology

Airflow was created at Airbnb in 2014 by Maxime Beauchemin and open-sourced in 2015. It became an Apache Top-Level Project in 2019. Airflow 2.x introduced the TaskFlow API which dramatically reduced boilerplate for Python-native pipelines.

3.1 Full ML Pipeline DAG (TaskFlow API)

The TaskFlow API (@task decorator, Airflow 2.0+) eliminates explicit XCom push/pull and makes Python-native pipelines feel natural. Return values are automatically XCom'd.
Python · dags/ml_training_pipeline.py
from __future__ import annotations
import json
from datetime import datetime, timedelta

from airflow.decorators import dag, task
from airflow.models import Variable
from airflow.operators.empty import EmptyOperator
from airflow.utils.trigger_rule import TriggerRule

DEFAULT_ARGS = {
    "owner": "ml-platform",
    "retries": 2,
    "retry_delay": timedelta(minutes=5),
    "retry_exponential_backoff": True,
    "email_on_failure": True,
    "email": ["ml-alerts@company.com"],
}

@dag(
    dag_id="ml_training_pipeline",
    default_args=DEFAULT_ARGS,
    schedule="0 2 * * *",          # 02:00 UTC daily
    start_date=datetime(2024, 1, 1),
    catchup=False,
    max_active_runs=1,
    tags=["ml", "training", "production"],
    params={
        "model_name": "fraud_detector",
        "min_auc": 0.85,
        "dataset_date": "{{ ds }}",
    },
)
def ml_training_pipeline():
    """End-to-end ML training pipeline with quality gate and conditional deploy."""

    @task(task_id="ingest_data")
    def ingest_data(**context) -> dict:
        """Pull yesterday's data from S3 into feature store."""
        from airflow.providers.amazon.aws.hooks.s3 import S3Hook
        ds = context["params"]["dataset_date"]
        s3 = S3Hook(aws_conn_id="aws_default")
        key = f"raw/events/{ds}/data.parquet"
        s3.get_key(key, bucket_name="ml-data-lake")
        return {"s3_path": f"s3://ml-data-lake/{key}", "date": ds, "row_count": 1_250_000}

    @task(task_id="validate_data")
    def validate_data(ingestion_result: dict) -> dict:
        """Run Great Expectations suite; raise on critical failures."""
        import great_expectations as ge
        path = ingestion_result["s3_path"]
        # In production: load GE checkpoint and run validation
        validation = {"passed": True, "path": path,
                      "rows": ingestion_result["row_count"]}
        if not validation["passed"]:
            raise ValueError(f"Data validation failed for {path}")
        return validation

    @task(task_id="preprocess_features")
    def preprocess_features(validation: dict, **context) -> dict:
        """Spark job to compute features; returns feature store reference."""
        from airflow.providers.apache.spark.hooks.spark_submit import SparkSubmitHook
        ds = context["params"]["dataset_date"]
        # In production: submit Spark job to EMR/Dataproc
        feature_uri = f"s3://ml-features/fraud/{ds}/features.parquet"
        return {"feature_uri": feature_uri, "feature_count": 128, "date": ds}

    @task(task_id="train_model")
    def train_model(features: dict, **context) -> dict:
        """Submit training job to SageMaker; poll for completion."""
        import boto3
        params = context["params"]
        sm = boto3.client("sagemaker", region_name="us-east-1")
        job_name = f"{params['model_name']}-{features['date'].replace('-', '')}"
        sm.create_training_job(
            TrainingJobName=job_name,
            AlgorithmSpecification={
                "TrainingImage": "763104351884.dkr.ecr.us-east-1.amazonaws.com/xgboost:1.7-1",
                "TrainingInputMode": "File",
            },
            RoleArn=Variable.get("sagemaker_role_arn"),
            InputDataConfig=[{"ChannelName": "train",
                              "DataSource": {"S3DataSource": {
                                  "S3Uri": features["feature_uri"],
                                  "S3DataType": "S3Prefix"}}}],
            OutputDataConfig={"S3OutputPath": "s3://ml-models/output/"},
            ResourceConfig={"InstanceType": "ml.m5.4xlarge", "InstanceCount": 1,
                            "VolumeSizeInGB": 50},
            StoppingCondition={"MaxRuntimeInSeconds": 7200},
            HyperParameters={"max_depth": "6", "eta": "0.1", "num_round": "200"},
        )
        # In production: use SageMaker sensor or wait_for_completion
        model_artifact = f"s3://ml-models/output/{job_name}/output/model.tar.gz"
        return {"job_name": job_name, "model_artifact": model_artifact}

    @task(task_id="evaluate_model")
    def evaluate_model(train_result: dict, features: dict, **context) -> dict:
        """Run offline evaluation; return metrics."""
        # Load model from S3, run evaluation on holdout set
        metrics = {"auc": 0.912, "f1": 0.873, "precision": 0.881,
                   "recall": 0.865, "job_name": train_result["job_name"]}
        return metrics

    @task.branch(task_id="quality_gate")
    def quality_gate(metrics: dict, **context) -> str:
        """Branch: deploy if AUC >= threshold, else alert."""
        threshold = float(context["params"]["min_auc"])
        if metrics["auc"] >= threshold:
            return "register_model"
        return "send_failure_alert"

    @task(task_id="register_model")
    def register_model(train_result: dict, metrics: dict, **context) -> dict:
        """Register model in MLflow Model Registry."""
        import mlflow
        mlflow.set_tracking_uri(Variable.get("mlflow_tracking_uri"))
        model_name = context["params"]["model_name"]
        with mlflow.start_run(run_name=f"airflow-{train_result['job_name']}") as run:
            mlflow.log_metrics(metrics)
            mlflow.log_param("artifact", train_result["model_artifact"])
            mlflow.register_model(f"runs:/{run.info.run_id}/model", model_name)
        return {"model_version": "latest", "model_name": model_name}

    @task(task_id="deploy_model")
    def deploy_model(registration: dict) -> None:
        """Trigger canary deployment via internal deploy service."""
        import requests
        resp = requests.post(
            Variable.get("deploy_service_url") + "/deploy",
            json={"model_name": registration["model_name"],
                  "version": registration["model_version"],
                  "strategy": "canary", "canary_pct": 5},
            timeout=30,
        )
        resp.raise_for_status()

    @task(task_id="send_failure_alert", trigger_rule=TriggerRule.ALL_DONE)
    def send_failure_alert(metrics: dict) -> None:
        """Post Slack alert with failure details."""
        import requests
        webhook = Variable.get("slack_webhook_url")
        requests.post(webhook, json={
            "text": f":x: Model quality gate FAILED. AUC={metrics['auc']:.3f} (threshold: {Variable.get('min_auc', 0.85)})"
        })

    end = EmptyOperator(task_id="end", trigger_rule=TriggerRule.NONE_FAILED_MIN_ONE_SUCCESS)

    # Wire up the DAG
    ingested    = ingest_data()
    validated   = validate_data(ingested)
    features    = preprocess_features(validated)
    trained     = train_model(features)
    metrics     = evaluate_model(trained, features)
    gate        = quality_gate(metrics)
    registered  = register_model(trained, metrics)
    gate >> [registered, send_failure_alert(metrics)]
    registered >> deploy_model(registered) >> end

dag_instance = ml_training_pipeline()

4. Airflow Best Practices for ML

Best Practices

4.1 Idempotency

Every Airflow task must be idempotent: running it twice for the same logical date should produce the same result without side effects. This enables safe retries and backfilling.

  • Use {{ ds }} (execution date) as a partition key in all writes.
  • Overwrite (not append) output partitions; never use auto-increment IDs as keys.
  • Use upsert semantics in databases (INSERT ... ON CONFLICT DO UPDATE).
  • Make training deterministic: fix random seeds, pin library versions.

4.2 XCom Best Practices

XCom size limit: XComs are stored in the Airflow metadata DB (Postgres). Keep values under 48KB. Never XCom DataFrames, model weights, or large arrays — use S3/GCS paths instead.

from airflow.decorators import dag, task
from airflow.models import TaskInstance, DagRun
from datetime import datetime, timedelta

def on_failure_callback(context: dict) -> None:
    """Called when any task fails. Posts to PagerDuty + Slack."""
    from airflow.providers.slack.hooks.slack_webhook import SlackWebhookHook
    ti: TaskInstance = context["task_instance"]
    dag_run: DagRun = context["dag_run"]
    hook = SlackWebhookHook(slack_webhook_conn_id="slack_ml_alerts")
    hook.send(
        text=(f":red_circle: *Task Failed*\n"
              f"DAG: `{ti.dag_id}` | Task: `{ti.task_id}`\n"
              f"Run: `{dag_run.run_id}` | Execution: `{context['ds']}`\n"
              f"Exception: ```{context.get('exception', 'unknown')}```"),
    )

def sla_miss_callback(dag, task_list, blocking_task_list, slas, blocking_tis):
    """Called when tasks exceed their SLA."""
    from airflow.providers.slack.hooks.slack_webhook import SlackWebhookHook
    hook = SlackWebhookHook(slack_webhook_conn_id="slack_ml_alerts")
    hook.send(text=f":warning: SLA missed in DAG `{dag.dag_id}`: tasks {task_list}")

@dag(
    dag_id="ml_pipeline_with_sla",
    default_args={
        "owner": "ml-platform",
        "retries": 2,

        "sla": timedelta(hours=2),          # All tasks must finish in 2h
    },
    schedule="0 1 * * *",
    start_date=datetime(2024, 1, 1),
    sla_miss_callback=sla_miss_callback,

)

        return "s3://bucket/data.parquet"

Python · dags/dynamic_model_dags.py
import yaml
from airflow.decorators import dag, task
from datetime import datetime

# Config-driven: one DAG per model in models.yaml
MODELS_CONFIG = yaml.safe_load(open("/opt/airflow/config/models.yaml"))

for model_cfg in MODELS_CONFIG["models"]:
    model_id   = model_cfg["id"]
    schedule   = model_cfg.get("schedule", "0 3 * * *")
    min_metric = model_cfg.get("min_auc", 0.80)

    @dag(
        dag_id=f"train_{model_id}",
        schedule=schedule,
        start_date=datetime(2024, 1, 1),
        catchup=False,
        tags=["ml", model_id],
        default_args={"owner": model_cfg.get("team", "ml-platform")},
    )
    def _make_dag(model=model_cfg):  # closure captures config
        @task
        def train() -> dict:
            print(f"Training {model['id']}")
            return {"auc": 0.90}

        @task.branch
        def gate(metrics: dict) -> str:
            return "deploy" if metrics["auc"] >= model["min_auc"] else "skip"

        @task
        def deploy(metrics: dict) -> None:
            print(f"Deploying {model['id']}")

        @task
        def skip() -> None:
            print(f"Skipping deploy for {model['id']}: quality gate failed")

        m = train()
        gate(m) >> [deploy(m), skip()]

    globals()[f"train_{model_id}"] = _make_dag()

6. Prefect

Alternative Orchestrator

Prefect was founded in 2018 with an explicit philosophy: "your code is the workflow." Unlike Airflow, where you define a DAG structure and then fill in operators, Prefect 2.x lets you decorate ordinary Python functions with @flow and @task. The runtime infers the DAG from the call graph.

Prefect Architecture

  • Prefect Server / Prefect Cloud: API server + UI for monitoring and scheduling.
  • Work Pool: Named queue backed by an executor (local, Docker, K8s, ECS, etc.).
  • Worker: Process that polls a work pool and executes flow runs.
  • Deployment: Versioned package of a flow + its schedule + infrastructure config.

    retries=3,

    cache_key_fn=task_input_hash,
    cache_expiration=timedelta(hours=12),

def ingest_data(run_date: str) -> dict:
    logger = get_run_logger()
    logger.info(f"Ingesting data for {run_date}")

    feature_path = artifact["path"].replace("data.parquet", "features.parquet")
    return {"feature_path": feature_path, "feature_count": 128, "date": artifact["date"]}

@task(name="Train Model", retries=1, timeout_seconds=7200, tags=["training", "gpu"])
def train_model(features: dict, hyperparams: dict) -> dict:
    logger = get_run_logger()
    logger.info(f"Training with features from {features['feature_path']}")
    # Real: submit to SageMaker / K8s / Ray
    run_id = prefect.runtime.flow_run.id
    return {"run_id": str(run_id), "artifact": "s3://ml-models/model.pkl",
            "hyperparams": hyperparams}

@task(name="Evaluate Model")
def evaluate_model(train_result: dict, features: dict) -> dict:
    metrics = {"auc": 0.913, "f1": 0.876, "run_id": train_result["run_id"]}
    prefect.artifacts.create_table_artifact(
        key="model-metrics",
        table=[{"Metric": k, "Value": v} for k, v in metrics.items()],
        description="Evaluation metrics for current training run",
    )
    return metrics

@task(name="Register and Deploy")
def register_and_deploy(train_result: dict, metrics: dict, model_name: str) -> None:
    import mlflow
    tracking_uri = Secret.load("mlflow-tracking-uri").get()
    mlflow.set_tracking_uri(tracking_uri)
    with mlflow.start_run(run_name=f"prefect-{train_result['run_id'][:8]}"):
        mlflow.log_metrics(metrics)
        mlflow.log_params(train_result["hyperparams"])

# ─── Flow ──────────────────────────────────────────────────────────────────────

@flow(
    name="ml-training-pipeline",
    description="Daily ML training pipeline with quality gate",
    version="2.1.0",
    timeout_seconds=10800,
    on_failure=[lambda flow, run, state: print(f"Flow failed: {state}")],
)
def ml_training_pipeline(
    run_date: str = str(date.today()),
    model_name: str = "fraud_detector",
    min_auc: float = 0.85,
    hyperparams: Optional[dict] = None,
) -> dict:
    logger = get_run_logger()
    if hyperparams is None:
        hyperparams = {"max_depth": 6, "n_estimators": 200, "learning_rate": 0.1}

    artifact  = ingest_data(run_date)
    validated = validate_data(artifact)
    features  = engineer_features(validated)
    trained   = train_model(features, hyperparams)
    metrics   = evaluate_model(trained, features)

    if metrics["auc"] >= min_auc:
        logger.info(f"Quality gate passed: AUC={metrics['auc']:.3f}")
        register_and_deploy(trained, metrics, model_name)
    else:
        logger.warning(f"Quality gate FAILED: AUC={metrics['auc']:.3f} < {min_auc}")
        raise ValueError(f"Model quality insufficient: AUC {metrics['auc']:.3f}")

    return metrics

if __name__ == "__main__":
    ml_training_pipeline()

7. Other Orchestrators

Landscape

Dagster

Dagster's central abstraction is the Software-Defined Asset (SDA): instead of tasks, you define data assets (tables, model files, features) and Dagster infers the pipeline from asset dependencies. This shifts thinking from "run this job" to "materialize this asset." It has native support for partitions, lineage, and type-checked outputs. See ch11b_dagster.html for a complete deep-dive.

Metaflow

Created at Netflix, Metaflow is optimized for data scientists: pipelines are Python classes, infrastructure concerns are handled by decorators (@kubernetes, @batch). Strong S3/artifact management. Less powerful scheduling than Airflow; best paired with a cron scheduler or Argo Workflows. No native UI unless using Metaflow Service + Outerbounds.

Luigi

Spotify's original workflow tool. Task-centric, simple dependency definition, no scheduler built-in (relies on cron). Still used in legacy ML systems but largely superseded by Airflow and Prefect. Good for simple pipelines where you need minimal infrastructure.

ZenML

ML-specific orchestration layer that sits on top of other orchestrators (Airflow, Kubeflow, Vertex AI Pipelines). Provides a portable pipeline abstraction with artifact stores, model registries, and stack components. Useful for teams that want portability across cloud providers without rewriting pipelines.

8. Event-Driven Orchestration

Advanced Patterns

Schedule-based pipelines (cron) are simple but wasteful — they run whether or not new data exists. Event-driven pipelines react to real-world signals: a new file lands in S3, a data quality check completes, model drift is detected. Airflow supports this via Sensors and Deferrable Operators.

sequenceDiagram participant S3 as S3 Bucket participant SNS as SNS/SQS participant Sensor as Airflow Sensor participant SCH as Scheduler participant Train as Training Task participant Mon as Monitoring Service S3->>SNS: New data file event SNS->>Sensor: Message received Sensor->>SCH: Trigger DAG run SCH->>Train: Execute training Train->>Mon: Log metrics Mon-->>SCH: Drift detected (HTTP callback) SCH->>Train: Trigger retraining DAG
Python · dags/event_driven_retraining.py
from airflow.decorators import dag, task
from airflow.providers.amazon.aws.sensors.s3 import S3KeySensor
from airflow.providers.http.sensors.http import HttpSensor
from airflow.sensors.base import PokeReturnValue
from airflow.operators.trigger_dagrun import TriggerDagRunOperator
from datetime import datetime, timedelta

@dag(
    dag_id="event_driven_retraining",
    schedule="*/15 * * * *",    # Poll every 15 min for new data
    start_date=datetime(2024, 1, 1),
    catchup=False,
    max_active_runs=1,
    default_args={"retries": 1},
)
def event_driven_retraining():
    # Deferred S3 sensor — releases worker thread while waiting
    wait_for_data = S3KeySensor(
        task_id="wait_for_new_data",
        bucket_name="ml-data-lake",
        bucket_key="incoming/{{ ds }}/data_*.parquet",
        wildcard_match=True,
        aws_conn_id="aws_default",
        poke_interval=60,
        timeout=3600,
        mode="reschedule",      # Releases worker slot between polls
        soft_fail=True,         # Don't fail if no data — just skip
    )

    # Check monitoring service for drift signal
    check_drift = HttpSensor(
        task_id="check_model_drift",
        http_conn_id="monitoring_api",
        endpoint="/api/drift/fraud_detector",
        request_params={"threshold": 0.05, "window_hours": 24},
        response_check=lambda response: response.json().get("drift_detected", False),
        poke_interval=300,
        timeout=600,
        mode="reschedule",
        soft_fail=True,
    )

    @task.branch(task_id="decide_trigger")
    def decide_trigger(ti=None) -> str:
        """Trigger retraining if new data arrived OR drift detected."""
        new_data = ti.xcom_pull(task_ids="wait_for_new_data") is not None
        drift    = ti.xcom_pull(task_ids="check_model_drift") is not None
        if new_data or drift:
            return "trigger_training_pipeline"
        return "no_action_needed"

    trigger = TriggerDagRunOperator(
        task_id="trigger_training_pipeline",
        trigger_dag_id="ml_training_pipeline",
        conf={"triggered_by": "event_sensor", "date": "{{ ds }}"},
        wait_for_completion=False,
    )

    @task(task_id="no_action_needed")
    def no_action() -> None:
        print("No new data and no drift detected — skipping retraining.")

    [wait_for_data, check_drift] >> decide_trigger() >> [trigger, no_action()]

9. Production Patterns

Production

Pattern 1: Daily Retraining with Multi-Stage Validation

Never deploy a freshly trained model directly to production. The pipeline should include: (1) offline evaluation against a holdout set, (2) comparison against the current production model (challenger/champion), (3) optional shadow deployment, and (4) gradual traffic rollout with automated rollback.

Python · dags/production_retraining.py
from airflow.decorators import dag, task
from airflow.models import Variable
from airflow.utils.trigger_rule import TriggerRule
from datetime import datetime, timedelta

QUALITY_GATES = {
    "min_auc":         0.85,
    "max_auc_delta":  -0.02,   # Challenger must not be >2% worse than champion
    "min_precision":   0.80,
    "max_latency_ms":  50,
    "min_data_rows":   500_000,
}

@dag(
    dag_id="production_retraining_pipeline",
    schedule="0 1 * * *",
    start_date=datetime(2024, 1, 1),
    catchup=False,
    max_active_runs=1,
    default_args={
        "owner": "ml-platform",
        "retries": 2,
        "retry_delay": timedelta(minutes=5),
        "email_on_failure": True,
        "email": ["ml-oncall@company.com"],
        "sla": timedelta(hours=3),
    },
    tags=["production", "retraining"],
)
def production_retraining_pipeline():

    @task
    def get_production_metrics() -> dict:
        """Fetch current champion model metrics from model registry."""
        import mlflow
        mlflow.set_tracking_uri(Variable.get("mlflow_tracking_uri"))
        client = mlflow.MlflowClient()
        versions = client.get_latest_versions("fraud_detector", stages=["Production"])
        if not versions:
            return {"auc": 0.0, "version": None}
        version = versions[0]
        run = client.get_run(version.run_id)
        return {"auc": float(run.data.metrics.get("auc", 0)), "version": version.version}

    @task
    def ingest_and_validate(**ctx) -> dict:
        ds = ctx["ds"]
        # Full data ingestion + Great Expectations validation
        rows = 1_350_000
        if rows < QUALITY_GATES["min_data_rows"]:
            raise ValueError(f"Insufficient data: {rows} < {QUALITY_GATES['min_data_rows']}")
        return {"path": f"s3://ml-data/{ds}/features.parquet", "rows": rows, "date": ds}

    @task(retries=1)
    def train_challenger(features: dict) -> dict:
        # Submit training job; return artifact location
        return {"artifact": "s3://ml-models/challenger/model.pkl",
                "run_id": "challenger-run-123"}

    @task
    def evaluate_challenger(train_result: dict) -> dict:
        # Run offline evaluation suite
        return {
            "auc": 0.917, "precision": 0.884, "recall": 0.872,
            "p99_latency_ms": 32, "run_id": train_result["run_id"],
            "artifact": train_result["artifact"],
        }

    @task.branch
    def multi_stage_gate(challenger: dict, champion: dict) -> str:
        """Apply all quality gates; fail fast with specific error."""
        reasons = []
        if challenger["auc"] < QUALITY_GATES["min_auc"]:
            reasons.append(f"AUC {challenger['auc']:.3f} < {QUALITY_GATES['min_auc']}")
        delta = challenger["auc"] - champion["auc"]
        if delta < QUALITY_GATES["max_auc_delta"]:
            reasons.append(f"AUC delta {delta:.3f} < {QUALITY_GATES['max_auc_delta']}")
        if challenger["precision"] < QUALITY_GATES["min_precision"]:
            reasons.append(f"Precision {challenger['precision']:.3f} below threshold")
        if challenger["p99_latency_ms"] > QUALITY_GATES["max_latency_ms"]:
            reasons.append(f"P99 latency {challenger['p99_latency_ms']}ms > {QUALITY_GATES['max_latency_ms']}ms")
        if reasons:
            print(f"GATE FAILED: {'; '.join(reasons)}")
            return "gate_failed"
        return "promote_to_staging"

    @task
    def promote_to_staging(challenger: dict) -> dict:
        """Register as Staging in MLflow; deploy to shadow environment."""
        import mlflow
        mlflow.set_tracking_uri(Variable.get("mlflow_tracking_uri"))
        client = mlflow.MlflowClient()
        client.transition_model_version_stage(
            name="fraud_detector", version=challenger.get("version", "1"),
            stage="Staging", archive_existing_versions=False)
        return {"stage": "staging", **challenger}

    @task
    def run_shadow_evaluation(staging: dict) -> dict:
        """Run shadow mode: route 1% real traffic, compare outputs."""
        # In production: compare shadow predictions to champion predictions
        shadow_divergence = 0.003   # 0.3% prediction divergence
        return {"divergence": shadow_divergence, **staging}

    @task.branch
    def shadow_gate(shadow: dict) -> str:
        return "promote_to_production" if shadow["divergence"] < 0.01 else "gate_failed"

    @task
    def promote_to_production(shadow: dict) -> None:
        import mlflow
        client = mlflow.MlflowClient()
        client.transition_model_version_stage(
            name="fraud_detector", version=shadow.get("version", "1"),
            stage="Production", archive_existing_versions=True)
        # Trigger canary: 5% → 25% → 100% over 1 hour via feature flags

    @task(trigger_rule=TriggerRule.ONE_SUCCESS)
    def gate_failed(challenger: dict, champion: dict) -> None:
        print(f"Deployment blocked. Champion ({champion['auc']:.3f}) retained.")
        # Trigger PagerDuty / Slack alert

    champion    = get_production_metrics()
    features    = ingest_and_validate()
    trained     = train_challenger(features)
    challenger  = evaluate_challenger(trained)
    gate_result = multi_stage_gate(challenger, champion)
    staged      = promote_to_staging(challenger)
    shadow      = run_shadow_evaluation(staged)
    shadow_res  = shadow_gate(shadow)

    gate_result >> [staged, gate_failed(challenger, champion)]
    shadow_res  >> [promote_to_production(shadow), gate_failed(challenger, champion)]

Pattern 2: Circuit Breaker for ML Pipelines

A circuit breaker prevents a repeatedly failing pipeline from exhausting resources and generating alert fatigue. After N consecutive failures, the circuit "opens" and the pipeline pauses until a human reviews the situation.

Python · plugins/circuit_breaker.py
from airflow.models import Variable, DagRun
from airflow.utils.state import State
from airflow.decorators import task
from datetime import datetime, timedelta

def check_circuit_breaker(dag_id: str, max_failures: int = 3) -> bool:
    """Return True if circuit is CLOSED (safe to run), False if OPEN (stop)."""
    from airflow.models.dagrun import DagRun
    from airflow.utils.session import create_session

    with create_session() as session:
        recent_runs = (
            session.query(DagRun)
            .filter(DagRun.dag_id == dag_id,
                    DagRun.execution_date >= datetime.utcnow() - timedelta(days=1))
            .order_by(DagRun.execution_date.desc())
            .limit(max_failures)
            .all()
        )
    if len(recent_runs) < max_failures:
        return True
    # Circuit OPEN if all recent runs failed
    all_failed = all(r.state == State.FAILED for r in recent_runs)
    if all_failed:
        Variable.set(f"circuit_open_{dag_id}", "1")
        return False
    Variable.delete(f"circuit_open_{dag_id}")
    return True

# Usage in DAG:
@task(task_id="circuit_breaker_check")
def circuit_breaker_check(**ctx) -> None:
    dag_id = ctx["dag"].dag_id
    if not check_circuit_breaker(dag_id, max_failures=3):
        from airflow.exceptions import AirflowSkipException
        raise AirflowSkipException(
            f"Circuit OPEN for {dag_id}: {3} consecutive failures. "
            "Requires manual intervention to reset."
        )
Production checklist for ML orchestration:
  • All tasks are idempotent (safe to retry)
  • XComs contain only paths/metadata — never raw data
  • Every pipeline has SLA + on-failure callback
  • Quality gates with numeric thresholds are in Variables (not hardcoded)
  • DAG files are in version control with CI validation
  • Sensitive credentials are in Airflow Connections/Secrets (not Variables)
  • Circuit breaker or max_active_runs=1 prevents runaway failures

Summary & Key Takeaways

1. Orchestration is non-negotiable at production scale. Ad-hoc cron + scripts fails when tasks have dependencies, need retries, or require audit trails. An orchestrator is the backbone of a reliable ML platform.
2. Airflow dominates enterprise ML. Its rich operator ecosystem, backfill capability, and managed offerings (MWAA, Cloud Composer, Astronomer) make it the default choice. The TaskFlow API in 2.x makes Python-native pipelines ergonomic.
3. Prefect excels for Python-native teams. Lower boilerplate, native result caching, and cleaner local dev experience. Best for teams that want to write flows, not operators.
4. Quality gates are the most important pattern. Never deploy automatically without evaluating challenger vs. champion metrics. Encode thresholds as Variables so non-engineers can tune them without code changes.
5. Event-driven beats schedule-driven when data is irregular. Use Sensors with mode="reschedule" to avoid blocking worker slots. Combine scheduled heartbeats with event triggers for robust coverage.
6. Test your DAGs like application code. DAG validation in CI (import errors, cycle detection, task count), unit tests for branching logic, and integration tests with dag.test() prevent silent breakage.
7. The orchestrator choice is less important than the patterns. Idempotency, quality gates, observability, and circuit breakers apply equally to Airflow, Prefect, or Dagster. Pick the tool your team will actually maintain.
