1. Why Infrastructure as Code for ML?

At Google and later at OpenAI, the most common source of non-reproducible model training runs was not bad code — it was infrastructure drift. Someone had SSH'd into a GPU node to "quickly fix" a CUDA library, or manually resized an EBS volume, or patched a security group rule without updating any documentation. By the time a bug surfaced three months later, nobody remembered what changed. Infrastructure as Code eliminates this entire class of problem.

1.1 The Manual Infrastructure Pain Points

Snowflake Servers

Each training node has been hand-crafted over months. Differences in kernel versions, CUDA drivers, and Python package state cause silent failures that are impossible to reproduce on a fresh cluster.

No Auditability

A compliance auditor asks "who opened port 22 to 0.0.0.0/0?" and nobody knows. Cloud consoles have weak audit histories. Git commits are the gold standard for change tracking.

Slow Environment Spinning

Recreating an experiment environment for a new team member takes days of tribal knowledge transfer — half the setup steps are undocumented institutional memory.

Cost Sprawl

Forgotten GPU instances, unattached EBS volumes, and idle endpoints cost millions per year at ML-scale organizations because nobody has a single pane of glass over provisioned resources.

Note: Workspaces vs. Separate State Files

Terraform workspaces share the same configuration code but use separate state files. For strict isolation between prod and dev (different AWS accounts, different permissions), prefer separate Terragrunt root modules over workspaces. Workspaces work well for lightweight feature-branch testing.

3. Terraform for GPU Clusters

Large-scale GPU training (LLM pre-training, diffusion models) demands more than just spinning up instances. You need placement groups for NVLink locality, EFA networking for RDMA-class bandwidth, and FSx for Lustre for parallel checkpoint I/O. Here is a production-grade configuration.

3.1 Full AWS p4d GPU Cluster with FSx for Lustre

# ===================================================
# gpu_cluster.tf — AWS p4d.24xlarge training cluster
# Optimized for large-scale LLM pre-training
# ===================================================

# Placement group — ensures all nodes in same network rack
resource "aws_placement_group" "llm_training" {
  name            = "${var.cluster_name}-llm-pg"
  strategy        = "cluster"
  spread_level    = "rack"
  partition_count = null  # null = cluster strategy
}

# Launch template with EFA + GPU-optimized settings
resource "aws_launch_template" "p4d_training" {
  name_prefix   = "${var.cluster_name}-p4d-"
  image_id      = data.aws_ami.efa_gpu.id
  instance_type = "p4d.24xlarge"

  # EFA — Elastic Fabric Adapter for 400 Gbps all-to-all
  # p4d.24xlarge has 4 x EFA interfaces
  dynamic "network_interfaces" {
    for_each = range(4)
    content {
      device_index                = network_interfaces.value
      network_interface_id        = null
      associate_public_ip_address = false
      subnet_id                   = element(module.vpc.private_subnets, 0)
      interface_type              = "efa"
      delete_on_termination       = true
      security_groups             = [aws_security_group.gpu_training.id]
    }
  }

  placement {
    group_name = aws_placement_group.llm_training.name
  }

  # NVMe SSD scratch (p4d has 8x 1TB NVMe)
  block_device_mappings {
    device_name = "/dev/xvda"
    ebs {
      volume_size           = 500
      volume_type           = "gp3"
      iops                  = 16000
      throughput            = 1000
      encrypted             = true
      delete_on_termination = true
    }
  }

  # GPU / EFA optimized user data
  user_data = base64encode(templatefile("${path.module}/templates/gpu_userdata.sh", {
    cluster_name     = var.cluster_name
    fsx_dns_name     = aws_fsx_lustre_file_system.training.dns_name
    fsx_mount_name   = aws_fsx_lustre_file_system.training.mount_name
  }))

  iam_instance_profile {
    arn = aws_iam_instance_profile.gpu_node.arn
  }

  metadata_options {
    http_endpoint               = "enabled"
    http_tokens                 = "required"  # IMDSv2 only
    http_put_response_hop_limit = 1
  }

  monitoring { enabled = true }

  tag_specifications {
    resource_type = "instance"
    tags = merge(var.tags, {
      Name = "${var.cluster_name}-gpu-training"
      "karpenter.sh/provisioner-name" = "gpu-training"
    })
  }

  lifecycle {
    create_before_destroy = true
  }
}

# GPU node security group (EFA requires all-traffic within SG)
resource "aws_security_group" "gpu_training" {
  name        = "${var.cluster_name}-gpu-training-sg"
  description = "Security group for GPU training nodes with EFA"
  vpc_id      = module.vpc.vpc_id

  # EFA requires unrestricted intra-SG traffic
  ingress {
    from_port = 0
    to_port   = 0
    protocol  = "-1"
    self      = true
  }

  # EKS cluster plane → nodes
  ingress {
    from_port       = 1025
    to_port         = 65535
    protocol        = "tcp"
    security_groups = [module.eks.cluster_security_group_id]
  }

  egress {
    from_port   = 0
    to_port     = 0
    protocol    = "-1"
    cidr_blocks = ["0.0.0.0/0"]
  }
}

EFA interfaces must be in a placement group within the same AZ. 5.3 When to Choose Pulumi over Terraform

  • Your IaC has complex business logic (dynamic resource counts based on API calls, conditional infrastructure)
  • Team is Python-heavy and writing Terratest feels foreign
  • You need native testing with pytest: mock providers, unit-test resource graphs
  • You're generating infrastructure from configuration objects (e.g., looping over a list of ML experiments to create isolated namespaces)
  • You want encrypted secrets stored in the stack state natively without Vault

from aws_cdk import (

    aws_sagemaker as sagemaker,
    aws_kms as kms,
    RemovalPolicy,
    Duration,
    CfnOutput,
)
from constructs import Construct
from typing import Optional


class MLPlatformStack(Stack):
    """
    Complete SageMaker ML platform stack.
    Includes Studio, S3 buckets, ECR, VPC, and IAM roles.
    """

    def __init__(
        self,
        scope: Construct,
        construct_id: str,
        env_name: str,
        **kwargs,
    ) -> None:
        super().__init__(scope, construct_id, **kwargs)

        self.env_name = env_name

        # ── VPC ─────────────────────────────────────────────────
        self.vpc = ec2.Vpc(
            self, "MLVpc",
            vpc_name=f"ml-platform-{env_name}",
            max_azs=3,
            ip_addresses=ec2.IpAddresses.cidr("10.0.0.0/16"),
            subnet_configuration=[
                ec2.SubnetConfiguration(
                    name="Private",
                    subnet_type=ec2.SubnetType.PRIVATE_WITH_EGRESS,
                    cidr_mask=24,
                ),
                ec2.SubnetConfiguration(
                    name="Public",
                    subnet_type=ec2.SubnetType.PUBLIC,
                    cidr_mask=24,
                ),
            ],
            nat_gateways=3,   # one per AZ for HA
        )

        # VPC endpoint for S3 (private access — no NAT egress cost)
        self.vpc.add_gateway_endpoint(
            "S3Endpoint",
            service=ec2.GatewayVpcEndpointAwsService.S3,
        )

        # VPC endpoint for SageMaker API
        self.vpc.add_interface_endpoint(
            "SageMakerAPIEndpoint",
            service=ec2.InterfaceVpcEndpointAwsService.SAGEMAKER_API,
        )

        # ── KMS Key ─────────────────────────────────────────────
        self.kms_key = kms.Key(
            self, "MLKmsKey",
            enable_key_rotation=True,
            alias=f"ml-platform-{env_name}",
            description=f"ML Platform encryption key ({env_name})",
            removal_policy=RemovalPolicy.RETAIN,
        )

        # ── S3 Buckets ───────────────────────────────────────────
        self.data_bucket = self._create_ml_bucket("data", versioned=True)
        self.artifacts_bucket = self._create_ml_bucket("artifacts", versioned=True)
        self.logs_bucket = self._create_ml_bucket("logs", versioned=False)

        # ── ECR Repository for training images ──────────────────
        self.training_repo = ecr.Repository(
            self, "TrainingRepo",
            repository_name=f"ml-training-{env_name}",
            image_scan_on_push=True,
            encryption=ecr.RepositoryEncryption.KMS,
            encryption_key=self.kms_key,
            lifecycle_rules=[
                ecr.LifecycleRule(
                    description="Keep last 20 tagged images",
                    tag_status=ecr.TagStatus.TAGGED,
                    max_image_count=20,
                ),
                ecr.LifecycleRule(
                    description="Remove untagged after 7 days",
                    tag_status=ecr.TagStatus.UNTAGGED,
                    max_image_age=Duration.days(7),
                ),
            ],
            removal_policy=RemovalPolicy.RETAIN,
        )

        self.studio_role = iam.Role(
            self, "StudioExecutionRole",
            role_name=f"sagemaker-studio-{env_name}",
            assumed_by=iam.ServicePrincipal("sagemaker.amazonaws.com"),
            managed_policies=[
                iam.ManagedPolicy.from_aws_managed_policy_name(
                    "AmazonSageMakerFullAccess"
                ),
            ],
        )

        # Grant S3 access
        self.data_bucket.grant_read_write(self.studio_role)
        self.artifacts_bucket.grant_read_write(self.studio_role)

        # Grant ECR access
        self.training_repo.grant_pull_push(self.studio_role)

        # ── SageMaker Studio Domain ──────────────────────────────
        studio_sg = ec2.SecurityGroup(
            self, "StudioSG",
            vpc=self.vpc,
            description="SageMaker Studio security group",
            allow_all_outbound=True,
        )

            self, "StudioDomain",
            auth_mode="IAM",
            default_user_settings=sagemaker.CfnDomain.UserSettingsProperty(
                execution_role=self.studio_role.role_arn,
                security_groups=[studio_sg.security_group_id],

                        instance_type="system",

                    )

                    default_resource_spec=sagemaker.CfnDomain.ResourceSpecProperty(
                        instance_type="ml.t3.medium",
                    )

            domain_name=f"ml-platform-{env_name}",
            subnet_ids=[s.subnet_id for s in self.vpc.private_subnets],
            vpc_id=self.vpc.vpc_id,
            app_network_access_type="VpcOnly",
            kms_key_id=self.kms_key.key_id,
            tags=[cdk.CfnTag(key="Environment", value=env_name)],
        )

        self.training_role = iam.Role(
            self, "TrainingRole",
            role_name=f"sagemaker-training-{env_name}",
            assumed_by=iam.ServicePrincipal("sagemaker.amazonaws.com"),
        )

        self.artifacts_bucket.grant_read_write(self.training_role)

        self,

            self, f"Bucket-{suffix.capitalize()}",
            bucket_name=f"ml-{self.env_name}-{suffix}-{self.account}",

            encryption=s3.BucketEncryption.KMS,
            encryption_key=self.kms_key,

                    ],
                )

name: Terraform Plan / Apply

on:
  pull_request:
    branches: [main]
    paths:
      - 'infrastructure/**'

  TF_VERSION:   "1.9.5"
  TG_VERSION:   "0.67.0"

  id-token:       write   # OIDC for AWS auth

  security-scan:
    name: Security Scan (Checkov + tfsec)
    runs-on: ubuntu-latest

      - name: Run Checkov
        uses: bridgecrewio/checkov-action@master

    runs-on: ubuntu-latest

    if: github.event_name == 'pull_request'
    strategy:
      matrix:
        environment: [dev, staging]

    steps:
      - uses: actions/checkout@v4

      - name: Configure AWS credentials (OIDC)
        uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-assume:      arn:aws:iam::${{ secrets[format('{0}_AWS_ACCOUNT', upper(matrix.environment))] }}:role/GitHubActionsRole

          role-session-name:   terraform-plan-${{ matrix.environment }}

      - name: Setup Terraform
        uses: hashicorp/setup-terraform@v3
        with:
          terraform_version: ${{ env.TF_VERSION }}

      - name: Setup Terragrunt
        run: |
          wget -q "https://github.com/gruntwork-io/terragrunt/releases/download/v${TG_VERSION}/terragrunt_linux_amd64"
          chmod +x terragrunt_linux_amd64

          terragrunt run-all init --terragrunt-non-interactive

            --terragrunt-non-interactive \

            2>&1 | tee plan_output.txt
          echo "exitcode=${PIPESTATUS[0]}" >> $GITHUB_OUTPUT

            const planOutput = fs.readFileSync(
              'infrastructure/live/${{ matrix.environment }}/plan_output.txt', 'utf8'
            );
            const truncated = planOutput.length > 60000
              ? planOutput.substring(0, 60000) + '\n...[truncated]'
              : planOutput;

            await github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner:        context.repo.owner,
              repo:         context.repo.repo,
              body: `## Terraform Plan — \`${{ matrix.environment }}\`
            \`\`\`
            ${truncated}
            \`\`\`
            **Exit code:** ${{ steps.plan.outputs.exitcode }}`
            });

      - name: Fail on Plan Error
        if: steps.plan.outputs.exitcode == 1
        run: exit 1

    name: Terraform Apply (prod)
    runs-on: ubuntu-latest
    needs: [security-scan]
    if: github.ref == 'refs/heads/main' && github.event_name == 'push'
    environment:
      name: production
      url:  https://console.aws.amazon.com/eks

      - uses: actions/checkout@v4

        uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-assume:    arn:aws:iam::${{ secrets.PROD_AWS_ACCOUNT }}:role/GitHubActionsRole
          aws-region:        ${{ env.AWS_REGION }}
          role-session-name: terraform-apply-prod

      - name: Setup Terraform + Terragrunt
        run: |
          curl -fsSL https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp.gpg
          echo "deb [signed-by=/usr/share/keyrings/hashicorp.gpg] https://apt.releases.hashicorp.com $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list
          sudo apt-get update && sudo apt-get install -y terraform=${TF_VERSION}
          wget -q "https://github.com/gruntwork-io/terragrunt/releases/download/v${TG_VERSION}/terragrunt_linux_amd64"

      - name: Terraform Apply
        working-directory: infrastructure/live/prod
        run: |
          terragrunt run-all apply \
            --terragrunt-non-interactive \
            --auto-approve

package terraform.ml.infrastructure

import future.keywords.contains
import future.keywords.every
import future.keywords.if

# ── Deny: S3 buckets without encryption ─────────────────────────
deny contains msg if {
  resource := input.resource_changes[_]
  resource.type == "aws_s3_bucket"
  resource.change.actions[_] in ["create", "update"]
  # Check encryption config is present
  not resource.change.after.server_side_encryption_configuration
  msg := sprintf(
    "S3 bucket '%s' must have server-side encryption configured. ML data must be encrypted at rest.",
    [resource.address]
  )
}

# ── Deny: EKS clusters without encryption for secrets ───────────
deny contains msg if {
  resource := input.resource_changes[_]
  resource.type == "aws_eks_cluster"
  resource.change.actions[_] in ["create", "update"]
  encryption_configs := resource.change.after.encryption_config
  not any_secrets_encryption(encryption_configs)
  msg := sprintf(
    "EKS cluster '%s' must encrypt Kubernetes secrets. Add encryption_config with resources=['secrets'].",
    [resource.address]
  )
}

any_secrets_encryption(configs) if {
  some config in configs
  "secrets" in config.resources
}

# ── Deny: GPU instances accessible from internet ─────────────────
deny contains msg if {
  resource := input.resource_changes[_]
  resource.type == "aws_security_group_rule"
  resource.change.after.type == "ingress"
  resource.change.after.cidr_blocks[_] == "0.0.0.0/0"
  resource.change.after.from_port < 1024
  msg := sprintf(
    "Security group rule '%s' opens a privileged port to the internet. GPU nodes must not be publicly accessible.",
    [resource.address]
  )
}

# ── Deny: IAM policies with wildcard actions ─────────────────────
deny contains msg if {
  resource := input.resource_changes[_]
  resource.type in ["aws_iam_policy", "aws_iam_role_policy"]
  resource.change.actions[_] in ["create", "update"]
  policy_doc := json.unmarshal(resource.change.after.policy)
  stmt := policy_doc.Statement[_]
  stmt.Effect == "Allow"
  stmt.Action == "*"
  msg := sprintf(
    "IAM policy '%s' uses wildcard Action '*'. ML workload roles must follow least-privilege.",
    [resource.address]
  )
}

# ── Warn: GPU nodes not in placement group ────────────────────────
warn contains msg if {
  resource := input.resource_changes[_]
  resource.type == "aws_eks_node_group"
  resource.change.actions[_] in ["create", "update"]
  contains(resource.change.after.node_group_name, "gpu")
  not resource.change.after.launch_template
  msg := sprintf(
    "GPU node group '%s' should use a launch template with a placement group for optimal NVLink performance.",
    [resource.address]
  )
}

# ── Deny: DynamoDB state lock table without encryption ────────────
deny contains msg if {
  resource := input.resource_changes[_]
  resource.type == "aws_dynamodb_table"
  contains(resource.address, "state-lock")
  resource.change.actions[_] in ["create", "update"]
  not resource.change.after.server_side_encryption[_].enabled
  msg := sprintf(
    "DynamoDB table '%s' (state lock) must have SSE enabled.",
    [resource.address]
  )
}

Summary & Key Takeaways

Terraform

  • Gold standard for multi-cloud IaC — use it unless you have a strong reason not to
  • Always use remote state (S3 + DynamoDB) from day one
  • Modules are your reusability primitive — publish them to a private registry
  • GPU clusters need placement groups and EFA security groups, not just instance type selection
  • FSx for Lustre is essential for checkpoint I/O above ~100 GB/s

Pulumi & CDK

  • Pulumi is powerful for ML teams — Python loops, testing with pytest, typed APIs
  • CDK is ideal if you're AWS-only and want CloudFormation rollback guarantees
  • CDK L3 constructs (Patterns) encode opinionated best practices — use them
  • All three tools converge on similar concepts: describe desired state, let the tool diff and apply

Terragrunt & GitOps

  • Terragrunt solves the DRY problem for multi-environment deployments
  • Use run-all to manage dependency graphs across modules
  • Atlantis for Terraform PR automation is the industry standard for team workflows
  • GitHub OIDC + IAM role assumption — no long-lived AWS credentials in CI

Policy as Code

  • Checkov + pre-commit catches misconfigurations before they reach PR review
  • OPA/Conftest enables custom organization-specific policy enforcement
  • Enforce: encryption at rest, no public GPU nodes, least-privilege IAM
  • Shift security left — a blocked git commit is cheaper than a blocked deploy

The Definitive IaC Stack for ML Platforms (2025)

  1. Terraform + Terragrunt for all cloud resources (VPC, EKS, S3, IAM)
  2. Helm + ArgoCD for Kubernetes manifests (covered in Ch12)
  3. Checkov + OPA for policy enforcement in CI
  4. Atlantis for PR-based plan/apply workflow
  5. GitHub OIDC for CI authentication — no static credentials
  6. Pulumi as an alternative when team prefers Python-first development
